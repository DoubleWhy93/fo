## Plain definitions / explanations

- [二十八讲·第18讲] **华严四智行法（别教、菩萨道种智行法）** (explained) 十住位之后、圆教八地之前的行法阶段，是华严不共法别教修行阶段，也就是菩萨道种智行法阶段，所成就的是极乐世界的实报庄严土。
  - 原文: 「這是華嚴不共法別教修行階段，也就是菩薩道種智行法階段。」
- [二十八讲·第19讲] **四智行法（菩萨道种智行法）** (explained) 华严经四十位行法，即世间而离世间，依普光明殿根本智所生起的入世间道种智行法，不能离根本智而运行。
  - 原文: 「四智行法是依根本智所生起的入世間道種智行法，道種智不能離開根本智而運行」
- [二十八讲·第21讲] **普光明殿与四智行法（体与用）** (defined) 说『普光明殿』是从一切法本体、根本智、一切智的角度；说『四智行法』是从一切法生起作用、差别智、道种智的角度；不能离开根本智、一切智单独生起差别智和道种智。
  - 原文: 「說『普光明殿』是從一切法本體的角度、從根本智、一切智的角度來說」
- [二十八讲·第26讲] **转八识成四智** (used) 十信位已说清楚是在身心觉知的一切法生起处转，从念念生起处转。
  - 原文: 「是在身心覺知的一切法生起處轉，從念念生起處轉」
- [七十讲·第3讲] **转八识成四智（入萨婆若海）** (explained) 用经典语言即入萨婆若海，这时看到的一切法就是自性中本有的一切法。
  - 原文: 「修行者能轉八識成四智，用經典語言來講就是入薩婆若海」
- [七十讲·第11讲] **四位行法（四智行法）** (defined) 住行向地四位行法即四智行法，是一个别教行法理论体系；以十住位六品为基础，十行、十回向、十地由十住位六品不断升进逐渐到达。
  - 原文: 「四位行法即四智行法，是一個別教行法理論體系。」
- [七十讲·第11讲] **转八识成四智** (explained) 佛教中说转八识成四智、转凡夫地一切法到诸佛世间一切法，即在住行向地四位行法处转。
  - 原文: 「佛教中說到轉八識成四智、轉凡夫地一切法到諸佛世間一切法即在此處轉」
- [七十讲·第61讲] **四智行法中的东方与北方** (explained) 东方代表大圆镜智，是一切法生起处；北方代表成所作智，是一切法现相处；生命中一切法皆从东方生起，最终在身心觉受中呈现于北方。
  - 原文: 「東方代表大圓鏡智，是一切法生起處；北方代表成所作智，是一切法現相處」

## Examples (author's analogies, cases, stories, dialogues)

- [七十讲·第2讲] (case) illustrates: 同一世间在不同种性眼中不同
  - setup: 世尊在《阿弥陀经》说『当知我于娑婆国土五浊恶世，成就无上正觉』；娑婆国土是凡夫种性看到的三界世间，世尊同样是在欲色无色界一切法中成就。
  - point: 凡夫要出离三界，成就者看同一世间就是四智法世间、极乐与华藏。
  - 原文: 「世尊同樣是在身心覺知的一切法中，在欲界、色界、無色界的一切法中成就無上正覺。」
- [七十讲·第4讲] (case) illustrates: 十位大自在天王要按十方来读
  - setup: 按《华严经》集结方式，十位大自在天王应从十个方向来定义；大自在天王这个生命因素按四智十方的模式展开成十位。
  - point: 十位天王是这一因素在十个方向上的具体呈现，考虑方向才知每位的意义。
  - 原文: 「大自在天王這個生命因素，按四智十方的模式展開成為十位」
- [七十讲·第5讲] (case) illustrates: 『为人演说一四句偈』是种性改变，不是解释文字
  - setup: 《金刚经》说为人演说这部经的一四句偈功德无量，这句话容易被错读为把文字讲清楚。
  - point: 讲者说它的意思是证得般若智慧后，身心觉知一切法皆在四智法清净世间，从凡夫种性成就到《金刚经》种性；转八识成四智、种性改变才算为人演说。
  - 原文: 「並非把文字解釋清楚，就叫作為人演說，不是！」
- [七十讲·第5讲] (case) illustrates: 同一经文的两种读法对应不同种性
  - setup: 对『四十二』『十位天王』等，过去人注解认为『十』代表圆满。讲者追问具体是怎样的圆满，答案是用四智十方或十波罗蜜的模式生起演说。
  - point: 圆满是指演说过程中对每一法如实知、如实体验，而不是数字本身吉祥。
  - 原文: 「但具體是怎樣的圓滿？就是用四智十方的模式，或者用十波羅蜜的模式來生起演說。」
- [七十讲·第9讲] (analogy) illustrates: 一法生起多法：用多个概念认识一个对象，概念即觉知观察和思惟
  - setup: 要认识一个苹果，要围绕苹果生起更多概念，如产地、颜色、种类，成分、味道、用途等；每增加一类信息，对苹果的认识就越丰富越准确，要了解更多就要继续生起更具体的内容，没有止境。
  - point: 说明生命中任何一法都可依四智十方模式生起觉知观察和思惟体验；观察思惟体验越多，能使用的名相越多，证得越深。
  - 原文: 「比如要認識一個蘋果，具體怎樣認識這個蘋果？」
- [七十讲·第17讲] (case) illustrates: 二乘声闻、别教菩萨靠作意转染为净，与菩萨行法的区别（非由思择有所制约有所防护）
  - setup: 二乘声闻、别教菩萨在分别取舍中建立行法，遇到善缘恶缘，往往告诉自己这是佛菩萨考验，不要生起贪著、不要生起瞋恚，诸法平等，要保持一心清净。
  - point: 这是靠作意思惟转变善恶染净；到菩萨行法则依主动自觉的力量生起，对一切法如实知、如实体验，并自觉做选择判断。
  - 原文: 「遇到善緣惡緣，往往會告訴自己這是佛菩薩考驗，不要生起貪著，不要生起瞋恚」
- [七十讲·第20讲] (case) illustrates: 『为人演说一四句偈』的真义
  - setup: 常有修行者认为一四句偈就是《金刚经》最后几句。讲者说不是：要到《金刚经》的成就处，转八识成四智，最低要到第七住位证诸法空，任何一法都能按四智法方式展开。
  - point: 这样才是『为人演说一四句偈』，所获功德才会『胜于三千大千世界七寶布施』。
  - 原文: 「任何一法都能按四智法的方式展開，這才是『為人演說一四句偈』」
- [七十讲·第34讲] (case) illustrates: 颜色的密法言说：青与白
  - setup: 极乐世界有青、黄、赤、白四色莲华，分别代表四智中的大圆镜智乃至成所作智；文殊以青师为坐骑，普贤以白象为坐骑。
  - point: 佛教行法实践从文殊智慧到普贤行法，即从青色指向白色；青色是自性本体、东方大圆镜智的颜色。
  - 原文: 「極樂世界有青、黃、赤、白四色蓮華，分別代表四智法中的大圓鏡智乃至成所作智」
- [七十讲·第42讲] (case) illustrates: 勤恳念佛拜佛却不见佛境界的原因
  - setup: 很多自称佛教修行者每天勤恳念佛、拜佛，乃至赞说诸佛功德，却仍不见诸佛菩萨广大境界。
  - point: 因为所念所拜所赞不是基于自性觉悟、当下生命体验，而是基于世间染净分别、模仿经文，或其他目的；不能自觉皈依自性觉悟，就是『本不修习见佛自在善根』。
  - 原文: 「儘管很多修行者自稱是佛教修行者，每天勤懇念佛、拜佛乃至讚說諸佛功德，但為什麼仍不見諸佛菩薩廣大境界」
- [七十讲·第43讲] (analogy) illustrates: 东南西北与四智、八识的对应
  - setup: 佛教经典常以东南西北代表四智，四智再对应凡夫地八识（东—大圆镜智—第八识；南—平等性智—第七识；西—妙观察智—第六识；北—成所作智—前五识），以『转八识成四智』的说法可知其对应。
  - point: 由此理解『一路向南』即以第七识『自我』因素皈依自性觉悟后生起无量精进行法，『东方』即一切法生起、种性成就处。
  - 原文: 「從佛教中『轉八識成四智』的說法亦可知它們之間以及四個方向是怎樣的對應關係」
- [七十讲·第51讲] (case) illustrates: 『所见诸佛悉由自心』：用心思惟改变的是心所觉受，不是诸法存在本身
  - setup: 一块石头砸在脚上产生疼痛，大体有三件事：石头砸到脚上；身所觉受的疼痛生起；心所觉受生起。前两件是因缘生法，第三件是依前两件生起的用心思惟。
  - point: 用心思惟不能改变前两件事的存在，但能改变其带来的心所觉受（喜怒哀乐、染净执取，或诸佛世界的庄严喜悦）；要改变前两件事需要身所作为，不是靠美好愿望或坚信石头不会砸到脚；凡夫于此一法生起娑婆世界的生死染著，解脱长者于此一法『见』十方诸佛世界的庄严喜悦。
  - 原文: 「比如一塊石頭砸在腳上產生疼痛，大體來說這裡有三件事」
- [七十讲·第57讲] (analogy) illustrates: 根本智如何了知差别智（『知一切众生诸病』）
  - setup: 英文中所有名相言说都依二十六个字母生起；二十六个字母本身没有善恶、美丑、染净、好坏之分，平等生起一切名相言说，而具体的名相言说则有各种不同意义。
  - point: 用经典语言说，就是二十六个字母『了知』一切名相言说。修行者以智慧力明了一切法，不是把字母本身息灭，而是在种种名相言说中以善用心、善思惟作出符合生命解脱与无上正觉的分别、选择、判断，止息生死染著的束缚。
  - 原文: 「用經典語言來說，即此二十六個字母『了知』一切名相言說。」

## How-to / step-by-step guidance

- [七十讲·第3讲] 怎样转入华严行法的观察模式
  - steps: 从染净模式（取净舍染）转到空有模式 → 遇缘而起，随缘而生，远离分别取舍 → 平等对待一切法，得梵行清净 → 到第七住以后，生起菩萨道种智行法
  - 原文: 「遇緣而起，隨緣而生，才能遠離對一切法的分別取捨」
- [七十讲·第4讲] 怎样把贪瞋痴慢习气转变成智慧种子
  - steps: 依《世界成就品》世界成就十种事一百个方面为基准 → 以贪瞋痴慢中的一法为种子 → 以四智十方为演说模式 → 对这一法生起觉知观察和思惟体验，生起种种分别、选择和判断，最终获生命解脱与无上正觉
  - 原文: 「對這一法生起覺知觀察和思惟體驗，生起種種分別、選擇和判斷」
- [七十讲·第9讲] 如何对生命中任意一法生起觉知观察与思惟体验
  - steps: 围绕该法这一核心，按四智十方模式生起更多概念（如蘋果的产地、颜色、种类、成分、味道、用途） → 每增加一类信息，认识就更丰富准确 → 继续生起更具体内容，没有止境 → 以准确理解与具体体验两个标准判断是否证得
  - 原文: 「要圍繞蘋果這個核心，生起更多的概念。」
- [七十讲·第11讲] 如何建立十信位行法（本页的两个认识）
  - steps: 认清从总相说，十信位仍在八识世间、未见性，同于凡夫外道二乘所在世间 → 认清从别相说，必须在五蕴身六入处一切法中成就，不能远离 → 去除异身、异时、异处的成就理念 → 以善用心、善思惟在一切法中得一心清净
  - 原文: 「建立十信位行法需要認清兩件事」
- [七十讲·第15讲] 怎样判断自己是否转入十住位
  - steps: 看是否在当下一切法中生起内在觉知模式的行法 → 对照标识：转八识成四智、见性、女转男身、证诸法空 → 体会『天帝释带领大众在须弥山顶迎佛入妙胜殿』的经典语言意趣，衡量自己是否到达
  - 原文: 「修行者可以通過一些標識來判斷是不是轉入十住位」
- [七十讲·第16讲] 怎样确定并解读法慧偈颂（及类似偈颂）
  - steps: 先确定这组偈颂的总体意义，再准确解读每一句 → 站在菩萨从东方而来、世尊上升须弥山顶、天帝释带大众迎佛、十住位行法生起、修行者自觉皈依自性觉悟的角度确定总体意义 → 把十首偈按十波罗蜜形式分开，每首四句按四智行法形式再分开，以此作为解读每一句的核心标准
  - 原文: 「這樣解讀每一句就有了核心標準」
- [七十讲·第16讲] 怎样从染净分别取舍的行法转入华严行法（入菩萨无量方便三昧）
  - steps: 从染净分别取舍模式的行法转变到一切法平等的空有模式的行法 → 以一念作意（对某一法关注）进入一一法别相，但不基于分别取舍而基于一切法清净平等 → 以善用心善思惟于一念作意中生起清净平等的如实知如实体验 → 乐住生死法界，不远离诸法因缘、不止息一切法生起
  - 原文: 「只有依空有模式的行法才能入菩薩無量方便三昧」
- [七十讲·第20讲] 怎样读《华严经》偈颂
  - steps: 先掌握偈颂的结构 → 按四智法形式去解读 → 结合该位行法的上首菩萨、本体三品与力用品结构
  - 原文: 「我們按四智模式去解讀，大體上不會有問題。」
- [七十讲·第41讲] 如何理解并进入一真法界
  - steps: 理解一真法界是一切法本然存在、普遍存在，也是五蕴六入十二处十八界一切法 → 如实知、如实体验身心觉知的一切法 → 从染净分别的行法模式转到诸法平等的菩萨行法模式 → 按十信、初住、第七住、初行……直至妙觉位逐阶段经历，不一蹴而就
  - 原文: 「修行者證得如來種性『一真法界』並非一蹴而就」
- [七十讲·第42讲] 如何才能『见佛』『见诸佛菩萨广大境界』
  - steps: 自觉皈依自性觉悟，不是模仿经文或为其他目的 → 安住当下的一切法 → 从染净分别取舍模式转到内在觉知模式的行法 → 以智慧力构建基于生命解脱与无上正觉的个体知识、经验和体验的思想体系，并在生命中获得体验
  - 原文: 「修行者必須要從染淨、分別、取捨模式的行法轉變到內在覺知模式的行法，才能走入華嚴行法，開啟自性智慧」
- [七十讲·第45讲] 怎样建立每一位次的菩萨行法并令成就地现前（经于七日）
  - steps: 依四智十方的智慧模式对一切法善观察、善思惟（东西南北四维上下观察求觅） → 不断训练摸索，积累行法资粮 → 在行法实践中不断调整、提高，直到安住这些资粮、超越一切法的束缚影响 → 这一法才现前
  - 原文: 「要在行法實踐中不斷調整、提高直到安住這些資糧，超越一切法的束縛和影響，才能令這一法現前」
- [七十讲·第56讲] 怎样准确解读某一位行法/某位善知识
  - steps: 不停留在文字名相的消文注释 → 对比不同位次同一位十波罗蜜行法的经文细节（经首、住处、成就法门、眷属等） → 把十波罗蜜四阶段、四智行法、等妙觉位等因素总合 → 把密法言说落实在行法实践中，反复审核、调整、提高，形成能自觉稳定生起的生命体验
  - 原文: 「將密法言說落實在行法實踐中，經歷反覆審核、調整、提高」
- [七十讲·第68讲] 怎样转八识成四智
  - steps: 以八识世间的一切法为基础，不止息八识世间的生命体验 → 通过学习和训练如实知、如实体验一切法 → 在行法实践中获得对一切法的如实知、如实体验
  - 原文: 「通過學習和訓練如實知、如實體驗一切法，獲得生命解脫與無上正覺」

## Teachings (definitions and criteria first)

- [二十八讲·第6讲] (definition) 凡夫种性的报身世间即娑婆世间；修行者转八识成四智、远离南阎浮提众生种性后，其报身世间的一切染著法即是阿弥陀如来极乐世界一切法；种性改变之后的娑婆世间即是极乐净土。
  - 原文: 「其報身世間一切染著法，事實上即是阿彌陀如來極樂世界一切法」
- [二十八讲·第12讲] (definition) 经典所说一四句偈代表一法的生住异灭成住坏空；了知则是演说一四句偈；转八识成四智才真正了解；菩萨种性者看任何一法生灭显现都是在演说一四句偈；一段文字亦可称一四句偈。
  - 原文: 「修行者轉八識成四智，才真正瞭解什麼是演說一四句偈。」
- [二十八讲·第18讲] (definition) 『世尊』代表修行者本有觉性，世尊不离菩提树指自性觉悟不离菩提场、身心觉知一切法、普光明殿；世尊上升四天宫四宝殿生起四十位行法，指华严四智行法需即世间而离世间，在世间一切法中成就，不同于别教行者远离世间的四智行法；须弥山顶代表正解脱，是即一切法而离一切法的解脱。
  - 原文: 「正解脫是即一切法而離一切法的解脫」
- [二十八讲·第19讲] (definition) 普光明殿是一切众生生命中本具的智慧报得处，是根本智所行处；四智行法是依根本智所生起的入世间道种智行法；四天宫四宝殿的演说处不是凡夫所能到达。
  - 原文: 「普光明殿是一切眾生生命中本具的智慧報得處，是根本智所行處」
- [二十八讲·第21讲] (definition) 『普光明殿』是从一切法本体、根本智、一切智的角度说，『四智行法』是从一切法生起作用、差别智、道种智的角度说；不能离开根本智、一切智单独生起差别智和道种智。
  - 原文: 「不能離開根本智、一切智而單獨生起差別智和道種智。」
- [二十八讲·第23讲] (definition) 十地位世尊眉间放光，意味着世间和出世间一切法皆可到无上正觉地，入世间一切行法皆是报身智慧的具体呈现；修行者于十地行法成就圆满菩萨道种智——从十住位破一念无明得无生忍，到不动地得无生法忍破一念无明尽，到法云地四智行法灌顶位；华严四智行法是从别教成就、证得一切法差别智的角度说。
  - 原文: 「圓滿菩薩道種智是指從十住位破一念無明得無生忍開始」
- [二十八讲·第25讲] (definition) 华严一乘行法不是要远离声闻缘觉、别教行者的行法；是到梵行清净后见一切法平等、没有分别取舍、随缘生起无量行法、成就无量法，不再舍一取一、是此非彼；即禅宗『悟后起修』；华严四智行法还没有完全到普贤法界，真正到梵行清净、一真法界一乘行法，是到普贤法界生起普贤行法。
  - 原文: 「生起華嚴一乘行法，並非是要遠離聲聞緣覺、別教行者的行法」
- [二十八讲·第26讲] (definition) 女转男身的意思即修行者转八识成四智，转世间烦恼生灭成出世间清净智慧。
  - 原文: 「女轉男身的意思即是修行者轉八識成四智」
- [七十讲·第3讲] (definition) 座内菩萨从本体上说，座外菩萨从显相上说；分十个是由四个类推：一法生起四法，是华严别教修行者生起萨婆若海一切法的模式，转八识成四智即一法生起四法；因要区分本体与显相演说时有一法，实际上显相四法之外没有单独的本体一法，任何一法的显相本身就是那一法的本体。
  - 原文: 「任何一法的顯相本身，就是那一法的本體。」
- [七十讲·第68讲] (definition) 与『八识』相比，『四智』是从根本智生起一切法的角度说，『八识』是从一切法所带来的生命体验、智慧力具体呈现的角度说。八识世间一切法是与生俱来、自性所生；转八识成四智并非止息八识、也非八识世间之外另有四智世间，而是以八识世间一切法为基础，通过学习和训练如实知、如实体验一切法而获得解脱与无上正觉。
  - 原文: 「修行者轉八識成四智並非『止息』八識世間的生命體驗而獨存四智法」
- [七十讲·第70讲] (definition) 第三部分中弥勒并未与善财一同入楼阁，而善财能见弥勒所有成就法，意味着弥勒菩萨行法遍一切处，此楼阁身即弥勒菩萨身；这是从弥勒无上智慧法身遍一切处成就的角度说，弥勒入一切法中无形无相，不以入出楼阁的形式呈现。四智行法中，此即到达妙觉位妙观察智的一切法。善财以见弥勒所有法而得无量总持门，得见十方清净眼，能见十波罗蜜所现一切境界，见种种世间种种众生，能观菩萨不思议事。
  - 原文: 「意味著彌勒菩薩行法遍一切處，此樓閣身即彌勒菩薩身」
- [七十讲·第70讲] (definition) 第四部分：弥勒『即摄神力入楼阁中，弹指作声』令善财从三昧起，意味着从对一切法总体的生命体验转变为具体的生命体验，代表妙觉位无上正觉总持力与自知自觉的『自我』因素总合为一，入遍一切处的一切法中。善财与弥勒的种种演说，意味着『自我』因素的如实知到达弥勒成就地，通过『自我』因素的反思、对话的形式，以名相言说的形式呈现；四智行法中，此即到达妙觉位成所作智的一切法。
  - 原文: 「這種印證通過『自我』因素的反思、對話的形式呈現」
- [二十八讲·第14讲] (criterion) 是否凡夫妄想要看是哪种作意模式；智慧的表现形式是微细观察和觉知思惟，是对一切法通达明了；华严四智行法十行位以后的行法就是这样的行法。
  - 原文: 「智慧的表現形式是微細觀察和覺知思惟，是對一切法通達明瞭」
- [二十八讲·第16讲] (criterion) 修行者转八识成四智，进入内在觉知模式，从染淨模式观察一切法转到空有模式观察；大乘菩萨以般若智慧到一心清净，观察一切有法皆是智慧法、皆是诸法实相，娑婆世界亦是庄严法界。
  - 原文: 「娑婆世界亦是莊嚴法界」
- [二十八讲·第17讲] (criterion) 华严行者到达空居天的行法模式不是共外道模式、不是世间法模式，而是内在觉知行法模式、出世间行法；所以确切说华严四智行法是在空居天的各个宝殿中演说，诸天中的宝殿意味着不是凡夫法外道法所能到达，但亦不离诸天模式而得成就；例如十住位在须弥山顶妙胜殿演说，十住位修行者虽上升须弥山顶但不同于凡夫外道，以妙胜殿行法模式于须弥山一切法中成就无量方便三昧，见自性地一切法。
  - 原文: 「華嚴經四智行法是在空居天的各個寶殿中演說」
- [二十八讲·第18讲] (criterion) 按华严行法，启发自性地文殊菩萨根本智慧、如实了知十信位，再经住行向地四智行法，到达等觉妙觉位的普贤菩萨法界，就到达华藏世界；最低要第八回向和第八地行法之后、金剛种性成就之后，逐渐转入普贤菩萨法界。
  - 原文: 「在華嚴行法中，最低要第八迴向和第八地行法之後，亦即金剛種性成就之後，逐漸轉入到普賢菩薩法界，即是到達華藏世界。」
- [二十八讲·第18讲] (criterion) 华严四位行法似在普光明殿以外演说，实际代表不离菩提场、普光明殿、世间一切法而成就四智行法；如《入法界品》文殊菩萨往诣福城东大塔庙，福城东并非固定世间处所，离开文殊菩萨所代表的自性地根本智慧，没有福城东；同样，离开普光明殿所代表的根本智慧，四天宫只是世间法，世间人乃至外道行者皆能到达，但四智行法在四天宫四宝殿生起，世间人和外道不能到达。
  - 原文: 「福城東並不是固定的世間處所，此處的核心還是文殊菩薩。」
- [二十八讲·第20讲] (criterion) 华严四智行法的经首都说『世尊不离菩提树』而上升诸天宫宝殿，代表四智行法不离自性觉悟、不离普光明殿、不离身心觉知一切法而别有。
  - 原文: 「則是代表了四智行法不離自性覺悟、不離普光明殿、不離身心覺知一切法而別有」
- [二十八讲·第21讲] (criterion) 四智行法三贤位经首都讲『世尊不离菩提树』而上升天宫和寶殿，是从别教行者报身智慧成就角度说，报身成就要靠自性智慧生起；三贤位还在即世间离世间的智慧法中，十地之前未到无上正觉入世间究竟成就处，所以有世尊『上升』天宫的说法。
  - 原文: 「三賢位還是在即世間離世間的智慧法中」
- [二十八讲·第23讲] (criterion) 十信位是依根本智所生起，不完全靠听闻善知识演说、靠闻法就能建立；到达十信位须完成从闻法模式到内在觉知模式理念上的转变，这是生起四智行法及所有行法的关键；华严第七住位是各种闻法模式行法所能到达的成就地。
  - 原文: 「這個轉變是生起四智行法以及所有行法的關鍵。」
- [二十八讲·第23讲] (criterion) 第七住位之后生起菩萨道种智行法，开始证得一切法别相，八地以后证得圆满；十信位依根本智一切法总相发心，依四智行法成就菩萨道种智，证得一切法别相到等觉位，才意味真实证得一切法。
  - 原文: 「此時才意味著真實證得一切法」
- [二十八讲·第23讲] (criterion) 四智行法在四天宫四宝殿演说，代表别教行法阶段修行者总体依然住清净世间，四智行法是即世间而离世间的菩萨道种智行法；以十住位证般若智慧得无生忍为基础，任何一法皆没有超越别教行法种性。
  - 原文: 「四智行法中的任何一法皆沒有超越別教行法種性」
- [二十八讲·第23讲] (criterion) 等觉位和妙觉如来地皆在普光明殿演说，意味着回到基于根本智一切法的成就模式；虽然普贤菩萨法界一切法众生自性本具，但必须经四智行法、成就圆满道种智之后才能到达；菩萨道种智依般若智慧生起，须在一切世界一切法中历经勤苦不断修行才能获得。
  - 原文: 「菩薩道種智是依般若智慧生起，在一切世界一切法中歷經勤苦不斷修行才能獲得」
- [二十八讲·第24讲] (criterion) 修行者到等觉位即超越四智行法；四智行法是别教模式的菩萨道种智行法，成就菩萨清净世间；等觉位转入普贤菩萨法界行法，不但到四智法清净世间，同时要能入一切世间成就一切法无有障碍；从十住到十地是从『破一念无明』到『破一念无明尽』，等觉位回到基于根本智的行法。
  - 原文: 「相對四智行法來說，等覺位普賢菩薩法界行法是回到基於根本智的行法。」
- [二十八讲·第24讲] (criterion) 《十定品》中『普眼菩萨于如来座前三请普贤菩萨而不见』：普眼最初以四智行法成就模式（入三昧法的清净行法模式）生起，所以不能见普贤；普贤法界不离四智法世间但非四智法世间，是依根本智的普贤行法生起；需消除四智行法中道种智行法习气、生起三昧法、生起清净智慧的习气才能到普贤法界。
  - 原文: 「消除生起三昧法、生起清淨智慧的習氣，才能到達普賢菩薩法界」
- [二十八讲·第24讲] (criterion) 广义说四智法到第八位行法即开始普贤菩萨法界行法，确切说须自性智慧能在世间应用、入世间一切法自在无碍时，即第八迴向位、第八地位以后，才开始普贤法界行法，到四智行法各位次灌顶位才进入等觉位，到达实际的普贤菩萨法界。
  - 原文: 「也就是要到第八迴向位、第八地位以後，才開始普賢菩薩法界行法」
- [二十八讲·第24讲] (criterion) 普贤十大愿王导归极乐，起码指四智行法皆要到第八位以后才算数，所导归的极乐世界一定要是无功用行所能成就；四智行法灌顶位在应用上即文殊普贤、观音弥勒四位菩萨；《普贤菩萨十大愿王导归极乐》强调面见阿弥陀佛有文殊普贤、观音弥勒四位菩萨接引，而非阿弥陀佛、观音、大势至现前接引。
  - 原文: 「而是強調面見阿彌陀佛，有文殊普賢、觀音彌勒四位菩薩的接引」
- [二十八讲·第24讲] (criterion) 一般说第七地之前是有余涅槃、第八地以后是无余涅槃，只是总的说别教四智行法，不非常准确；从华严行法理论看，到妙觉位才是究竟无余涅槃；每个种性行法成就不同，每次种性改变都是本质提升；修行者要自知自觉行法所在，也要能知他人所说行法所在，才不至于迷惑。
  - 原文: 「到達妙覺位才是究竟無餘涅槃」
- [二十八讲·第28讲] (criterion) 从四智行法说，第七位是该行法有功用行圆满位，第八位到第十位是该行法『身口意』入灭尽定、开始无功用行行法；两参不相间隔表示无功用行的成就地不在别处，就在有功用行的成就处；有功用行地、无功用行地、无生忍与无生法忍，都在世间一切法、身心觉知一切法中精进修行所得，不是别有成就处所。
  - 原文: 「代表是說無功用行行法的成就地不在別處，即是在有功用行的成就處」
- [七十讲·第5讲] (criterion) 《金刚经》中『为人演说一四句偈功德无量』容易被错读：它是说进入《金刚经》行法模式、证得般若智慧后，身心觉知的一切法皆在四智法清净世间；是从声闻种性、凡夫种性成就到《金刚经》种性、自性般若智慧生起，是种性上的改变；能转八识成四智，种性改变才算『为人演说一四句偈』。
  - 原文: 「在《金剛經》行法中，能從凡夫地到見性地，能轉八識成四智，修行者種性改變才算『為人演說一四句偈』。」
- [七十讲·第16讲] (criterion) 修行者转八识成四智，生命中一切法皆入萨婆若海；过去人说自性本自具足、自性能生万法；到第七住位就能明了，而只有生起菩萨道种智行法才知道自性如何本自具足、如何能生万法，即住行向地四位行法。
  - 原文: 「修行者到達第七住位，就能明瞭自性本自具足、自性能生萬法」
- [七十讲·第55讲] (criterion) 生命中的『佛法僧』三根本因素、十波罗蜜、四智行法等皆非抽象固定的概念，需明了它们在不同行法位次中的确切表现，才能如实知行法实践所在；解读某一位行法、某一位善知识具体成就时，一定要把相关属性放到经文整体环境中准确理解，如实准确解读经典亦是行法实践的一部分。
  - 原文: 「如實、準確解讀經典亦是行法實踐的一部分」
- [七十讲·第64讲] (criterion) 生命体验是在行法实践过程中，逐渐从娑婆世界转变到极乐世界和华藏世界。佛教也讲阿赖耶识中的一切法：从出于本体的一切法普遍存在的角度讲，『如来藏』一切法即阿赖耶识中的一切法；从生命体验的角度讲，修行者至少要到证诸法空得无生忍、在一切法中得梵行清净，亦即到转八识成四智的行法阶段，才能逐渐体会『如来藏』一切法。
  - 原文: 「修行者至少要到達證諸法空得無生忍、在一切法中得梵行清淨，亦即到達轉八識成四智的行法階段」
- [七十讲·第68讲] (criterion) 对一切法的『如实知、如实体验』不是与生俱来，需要在行法实践中获得，此即转八识成四智；离开它，八识世间即凡夫地娑婆世界；具备它，八识世间即极乐世界、华藏世界。
  - 原文: 「如果具備對一切法的如實知、如實體驗，八識世間即極樂世界、華藏世界」
- [二十八讲·第26讲] (method) 建立华严十信位才能生起四智行法；转八识成四智在什么地方转、怎样转、转到什么标准，普光明殿十信位已说清，是在身心觉知一切法生起处转；福城东大塔廟会又说明十信位的具体落实，修行者需依文殊菩萨智慧生起入世间行法。
  - 原文: 「修行者需要依文殊菩薩智慧生起入世間行法」
- [七十讲·第3讲] (method) 能转八识成四智，即入萨婆若海，看到的一切法就是自性中本有的一切法；生起内在觉知模式的行法，对五蕴身、六入处一切法如实知，在此基础上成就菩萨道种智；道种智行法成就在生命体验中呈现十方世界、庄严法界。
  - 原文: 「對五蘊身、六入處一切法能如實知，在此基礎上來成就菩薩道種智」
- [七十讲·第9讲] (method) 十信位要求依当下身心觉知的一切法建立观察觉知和思惟体验，从这里生起华严十信位行法；依此十信行法才能转八识成四智，生起别教菩萨四智行法，最终到等妙觉如来地的所有成就。
  - 原文: 「才能轉八識成四智，才能生起別教菩薩四智行法」
- [七十讲·第16讲] (method) 法慧菩萨这组偈颂共十首四十句，是站在种性成就角度说的；按十波罗蜜形式分开十首偈，每首偈四句再按四智行法形式分开，解读每一句就有了核心标准；从法数生起方式看，从一组偈颂生起十首偈再生起四十句，最终可到无量演说；法数解读可参考《觉悟华严经·总释二十八讲》。
  - 原文: 「將這十首偈頌按十波羅蜜形式分開，每一首偈的四句按四智行法的形式再分開，這樣解讀每一句就有了核心標準。」
- [二十八讲·第16讲] (warning) 有人以为消除有法习气是要消除一切法生起习气，甚至消除对一切法的觉知思惟，这不正确；佛在很多经典申明，不能以息灭觉知思惟、以识的息灭来证大涅槃出离生死；华严四智行法十行位以后都是生起观察觉知思惟的行法，大乘菩萨并非息灭第七意识作用；凡夫不如理作意使众生身处南阎浮提、六道轮回，菩萨的了别作意、胜解作意、精进加行作意等如理作意可带领修行者远离凡夫生死，是道种智行法不可缺少的因素。
  - 原文: 「修行者不能以息滅覺知思惟，以識的息滅來證得大涅槃以出離生死」
- [二十八讲·第19讲] (warning) 人天外道、声闻权教乃至共法别教修行者所理解的四智行法与华严四十位行法不同，不是四智本身意义不同，而是行者认知不同；在声闻权教别教行者看来八识世间与四智世间独立分开，如认为离开地球别有一个极乐世界；有人认为一念不生是关闭身心觉知，一念生起即入凡夫种性，要在身心觉知之外成就四智世间，这是佛在经典明确否定的修行理念。
  - 原文: 「在有些修行者看來，一念不生意味著關閉身心覺知，一念生起即入凡夫種性」
- [二十八讲·第23讲] (warning) 没有经历四智行法、没有成就金刚种性菩萨道种智，就不可能生起普贤菩萨法界行法；认为普贤十大愿王导归极乐看似不难样样能做是大误解，普贤法界行法须成就金刚种性道种智，按次第不能跳跃。
  - 原文: 「不能跳躍」
- [二十八讲·第24讲] (warning) 凡夫种性、二乘声闻、权教别教修行者若没有到达华严四智行法、没有成就金刚种性，就不能生起等觉位普贤菩萨法界行法；觉得普贤十大愿王导归极乐不难是大误解，因不了解金刚种性成就地；必须到金刚种性、菩萨道种智圆满，按次第不能跳跃。
  - 原文: 「是因為不瞭解什麼是金剛種性成就地」
- [二十八讲·第28讲] (warning) 第十法云地只是华严经别教四智行法的灌顶位，并未到真实的如来座前普贤菩萨法界，未到圆满如来地一切智智；释女瞿波与佛陀是不同的两个人，一个是出世间圆满智慧，一个是入世间慈悲行法。
  - 原文: 「第十法雲地只是華嚴經別教四智行法的灌頂位，並未到達真實的如來座前普賢菩薩法界」
- [七十讲·第20讲] (warning) 《金刚经》『为人演说一四句偈』功德胜过三千大千世界七宝布施，不是指《金刚经》最后那几句，而是修行者要到《金刚经》的成就处，转八识成四智，最低要到第七住位证诸法空，任何一法都能按四智法方式展开。
  - 原文: 「常有修行者認為一四句偈就是《金剛經》最後那幾句，不是這樣！」
- [七十讲·第33讲] (warning) 有一种观点认为转到极乐世界或转八识成四智后，娑婆世界、八识世间一切法悉皆息灭，只剩极乐世界、四智世间，把二者对立起来，讲者说不是这样！因为有众生生命参与才有娑婆、极乐、八识、四智世间；没有生命参与，一切法普遍存在世间无有这些区别。
  - 原文: 「將娑婆世界與極樂世界、八識世間與四智世間對立起來，不是這樣」
- [七十讲·第56讲] (warning) 十波罗蜜行法并非抽象的、固定的、与生命体验无关的概念；修行者不能只停留在对文字名相的消文注释上，要将十波罗蜜四阶段、四智行法、等妙觉位等因素总合，把密法言说落实在行法实践中。
  - 原文: 「十波羅蜜行法並非抽象的、固定的、與生命體驗無關的概念」
- [二十八讲·第14讲] (structure) 第八阿赖耶识的一切有法在凡夫地是生死法、业力所成的须弥山；转入四智行法后阿赖耶识转成大圆镜智，一切法生起即入萨婆若海，须弥山即七宝所成楞伽山、普陀洛迦山；这是要从染淨法观察调整到空有法观察的原因。
  - 原文: 「阿賴耶識轉成大圓鏡智，一切法生起即入薩婆若海」
- [二十八讲·第14讲] (structure) 十行位四品，十回向位三品，十地位一品，并非六品结构；从十住到十地是完整的华严四智行法，十行到十地不离十住单独存在，皆以十住为核心次第生起，四位合起来是华严别教四智行法；经文言说逐渐融合以凸显体用成就合一。
  - 原文: 「其中十行位四品，十迴向位三品，十地位一品」
- [二十八讲·第15讲] (structure) 二十波罗蜜是十波罗蜜的作用生起，核心仍以十波罗蜜为说法种子；华严经中任何一法生起无量法皆按十波罗蜜的体用模式展开；一法种子以十波罗蜜为演说模式次第生起世间显相，以四智行法演说总体生起四十个波罗蜜法，即华严经普光明殿四十位行法，修行者有这四十位行法才能到达华藏世界。
  - 原文: 「這四十個波羅蜜法在華嚴經普光明殿即是四十位行法」
- [二十八讲·第16讲] (structure) 第二处普光明殿演说四个阶段六位行法，三十二品经文；六位行法是依过去人的说法按经首划分，按佛陀时代行法理论划分则十住到十地是单独完整的四智行法（菩萨道种智行法）；六位行法分四个阶段，对应佛陀时代行法理论的四禅与四果（需按华严圆教行法理论诠释）。
  - 原文: 「六位行法分作四個階段，對應佛陀時代行法理論的四禪與四果」
- [二十八讲·第17讲] (structure) 第一处菩提场有六品经，按体用演说佛法僧；第二处普光明殿有三十二品，演说从十信位经四智行法到等妙觉位如来地；第三处入法界一品分三会（逝多林本会、福城东大塔庙会、善财五十三参）。
  - 原文: 「第二處普光明殿有三十二品經，演說修行者從十信位，經歷四智行法，到達等妙覺位如來地的行法理論」
- [二十八讲·第17讲] (structure) 普光明殿六位行法中十信、十住、等觉、妙觉都是六品经，与菩提场会六品结构相同，也按体用模式演说佛法僧；十住位是四智行法的发起处，十住、十行、十回向、十地是完整的华严不共别教行法，即菩萨道种智行法，围绕四智法生起的详细演说。
  - 原文: 「普光明殿十住位是四智行法的發起處，十住、十行、十迴向、十地是完整的華嚴不共別教行法」
- [二十八讲·第17讲] (structure) 欲界须弥山顶以上是夜摩天、兜率天、乐变化天、他化自在天，这些是空居天，虽在须弥山顶以上但不离须弥山；须弥山代表生命中的一切法，基于一切法的观察觉知，在不同模式下看就是四个空居天；空居是不受须弥山顶以下生死色法影响或影响越来越小，需定力到达；从华严行法理论看，佛教成就不离世间一切法，所以四智行法在空居天演说。
  - 原文: 「從華嚴行法理論來看，佛教成就不離世間一切法，所以四智行法是在空居天演說」
- [二十八讲·第18讲] (structure) 十住位修行者是生起内在觉知模式行法的修行者；在到达普贤菩萨法界之前（圆教八地之前）处于华严四智行法阶段，即华严不共法别教修行阶段、菩萨道种智行法阶段，所成就的是极乐世界的实报庄严土，其种性即法藏比丘的种性。
  - 原文: 「這個階段的修行者即是《無量壽經·法藏因地品》中法藏比丘的種性。」
- [二十八讲·第18讲] (structure) 《觉悟华严经》不采用上述判别，而把四天宫演说四十位行法统一到四智行法来诠释；四智行法是华严别教行法，即见性菩萨的道种智行法，依差别智生起，不同于十信位与等妙觉位；四智行法并行成就，同时又次第生起。
  - 原文: 「四智行法是並行成就，同時又是次第生起。」
- [二十八讲·第18讲] (structure) 十行位在夜摩天宫宝庄严殿演说，演说模式与十住位相同，不是世尊离开普光明殿转到别处，而是四智行法的平等性智一定要以般若智慧力，在世间法中以夜摩天普观一切世间法的模式生起，即功德林菩萨入『菩萨善思惟三昧』后演说十行位；十回向位在兜率天宫一切妙宝所庄严殿、十地位在他化自在天宫摩尼宝藏殿，同样意义。
  - 原文: 「來成就四智法即世間離世間平等性智」
- [二十八讲·第18讲] (structure) 华严经四位行法是完整的四智法理论体系；普光明殿六位行法分作四个阶段：十信位、四智行法、等觉位、妙觉位。
  - 原文: 「六位行法分作四個階段：第一階段是十信位，第二階段是四智行法，第三階段是等覺位，第四階段是妙覺位。」
- [二十八讲·第19讲] (structure) 四十位行法即华严四智行法、菩萨道种智行法；即世间指在须弥山顶、夜摩天宫、兜率天宫、他化自在天宫演说，离世间指世尊不离菩提树、菩提场、普光明殿而往诣四天宫四宝殿，由四大菩萨演说。
  - 原文: 「而離世間的意義就是這些演說都是世尊不離菩提樹、不離菩提場、不離普光明殿而往詣四天宮四寶殿，是由四大菩薩演說。」
- [二十八讲·第19讲] (structure) 华严四智行法是依须弥山顶妙胜殿成就大圆镜智，依夜摩天宫宝庄严殿成就平等性智，依兜率天宫一切妙宝所庄严殿成就妙观察智，依他化自在天宫摩尼宝藏殿成就成所作智；四智行法即菩萨道种智行法。
  - 原文: 「依須彌山頂妙勝殿成就大圓鏡智，依夜摩天宮寶莊嚴殿成就平等性智」
- [二十八讲·第19讲] (structure) 四智行法详细内容须结合具体经文，包括说法处所、上首众种类、法数显现、说法主名号、所从来处、所入三昧、说法因缘、所说偈颂等。
  - 原文: 「包括說法處所、上首眾種類、法數顯現、說法主名號、所從來處、所入三昧、說法因緣，以及所說偈誦等等」
