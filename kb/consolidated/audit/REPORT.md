# 声明审计报告（Phase 4）

独立审读者对照来源页上下文，核查了 240 条声明：低重叠的 109 条 + 分层抽样 131 条（20 张概念卡、6 张框架卡）。

| 结论 | 条数 |
|---|---:|
| supported（有据） | 197 |
| partly（部分有据） | 39 |
| unsupported（无据，实为不冲突的“分歧”） | 4 |
| misattributed / cannot_tell | 0 |

**主要问题类型**
1. 声明多出一小句引文里没有的内容（常见于 definition 的末尾“落位”句）。
2. 把提问者的话或讲者的推测写成讲者陈述。
3. “分歧”其实是互补说法（不同层次/术语），不构成冲突。
4. 引文选错了句（同页别处才是证据）。

**处理**：partly 条目按审读者建议文字改写；4 条 unsupported 的分歧已从卡中移除；未发现 misattributed。
抽样结果：约 82% 有据、约 16% 部分有据、<2% 无据 —— 其余未审的卡（约 90%）可预期有类似比例的“多一小句”问题，使用时以原文引文为准。
