華嚴書院學員守則 
一、宗旨與發心 
1. 本書院爲非營利性質之學習共同體，以共同研習《華嚴經》、熏習
正知正見、增長智慧與慈悲爲宗旨。 
2. 學員應以恭敬心、學習心與利他心參與書院活動，不以名利、爭勝
或個人私欲爲學習目的。 
3. 鼓勵長期、穩定、循序漸進的學習態度，反對急功近利與浮躁之學
風。 
二、學習態度與行爲規範 
1. 學員應尊重經典、尊重法義，在學習與討論中保持謙遜、真誠與審
慎。 
2. 課堂學習應專注守時，不隨意打斷他人發言，不進行與學習無關的
活動。 
3. 討論問題應圍繞經文與義理展開，避免情緒化爭論、個人攻擊或炫
耀知識。 
4. 鼓勵提問與探討，但應以求法爲本，不以挑戰、抬槓或顯示聰明爲
目的。 
三、師友與同學關繫 
1. 尊重授課老師、輔導人員及組織者，遵守課程安排與學習引導。 
2. 同學之間應以善意、包容、互助爲原則，不拉幫結派，不排斥他人。

<!-- p2 -->

3. 不對他人的修學程度、理解深淺、個人背景作價值評判。 
4. 對不同理解與見解，應以討論、參考與反思的態度對待。 
四、言語與交流規範 
1. 學員在書院線下或線上交流平臺中，應使用文明、誠懇、剋制的語
言。 
2. 禁止任何形式的侮辱、歧視、譏諷、挑釁或傳播不實信息。 
3. 不隨意轉發未經核實的法義觀點、他人私人發言或內部學習資料。 
4. 交流中如出現分歧，應以和合爲重，必要時可交由書院管理人員協
調。 
五、學習紀律與參與要求 
1. 學員應儘量按時參加課程與共學活動，如因故缺席，應提前說明。 
2. 鼓勵按書院安排完成閱讀、聽講與思考任務，但不以強制或考核爲
目的。 
3. 不得以書院名義從事任何商業、募資、推銷或個人宣傳行爲。 
4. 不得擅自以書院名義對外發佈聲明、課程解釋或法義立場。 
六、非營利與清淨原則 
1. 本書院不進行任何營利性活動，所有學習資源僅用於共學目的。 
2. 學員不得藉學習之名進行個人崇拜、派別宣傳或不當影響。 
3. 尊重不同法門與修學路徑，不貶低、不對立、不製造紛爭。 
4. 不得私下散發、推銷與本書院不相關的各種媒體、材料。

七、守則的理解與執行 
1. 本守則旨在護持清淨學習環境，並非約束個人信仰或思想自由。 
2. 如學員行爲嚴重影響書院正常學習秩序，書院有權進行提醒、勸導
或暫停其參與資格。 
3. 守則可根據書院發展需要適度修訂，並提前向學員說明。 
4. 願以此共學之緣，熏習華嚴智慧，成就自利利他之行。
