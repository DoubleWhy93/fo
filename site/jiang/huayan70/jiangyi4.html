华严七十讲

第四讲

要点讲《世主妙严品》二十位菩萨与四十类围绕众：往昔是行法模式而非历史，围绕众即我们身心觉知的一切法，诸龙与阿修罗王等恶法习气如何转成智慧种子，并讲流水文的解读、行法精进的十个方面与偈颂。

概述

讲者先说『往昔、现在、未来』指发心模式、行法模式、成就模式，时间与空间（如『从是西方，过十万亿佛土』）都是种性差别的密法言说；经典『演说』有语言音声、文字名相、身心觉受、诸法如实呈现四种。《世主妙严品》只讲呈现，不讲具体行法，行法理论在普光明殿；四十二类围绕众即四十位行法（十住至十地）加座前二十菩萨，生起次序与十信位的回到本体呼应。接着讲诸龙发菩提心＝烦恼习气皈依自性觉悟，阿修罗王『摧伏我慢及诸烦恼』是显现模式改变而体性不变，并批评凡夫外道、二乘声闻共法别教以厌离、观身不净为行法的局限，主张『乐住生死，主导世间』与从染净模式转到空有模式。后半讲生起顺序与成就法门演说顺序相反、流水文的读法（以六方佛赞为例）、行法精进须从十个方面（一法生十法百法）说清而非苦行，最后预告偈颂的解读须先看结构。

  • 横遍十方、竖穷三际

  • 何期自性，能生万法

  • 普光明殿三个经首：《如来名号品》《十定品》《离世间品》

主要观点

  • 二十位菩萨（座内十普、座外十别）与毘卢遮那佛的因缘用『往昔』一词；大乘经典中的往昔现在未来指修行者发心模式、行法模式、成就模式，从因相、自相、果相及行法实践、生命体验的角度说。
    指的是修行者的发心模式、行法模式、成就模式
  • 经典讲同一行法的不同阶段（从初发心到行法实践到成就地）常按时间顺序：初发心处是往昔，行法实践在当下，成就地是未来；讲种性差别时则从空间距离说。
    初发心处是往昔过去，而成就地是未来
  • 时间和空间都代表要在行法实践、生命体验中呈现，是从道种智行法角度说；《阿弥陀经》『从是西方，过十万亿佛土』是从空间距离说娑婆世界与极乐世界种性上的差别；释迦牟尼佛的净土『从是西方，过三十二亿恒河沙国土』也是讲种性上的差别。
    释迦牟尼佛的净土是『从是西方，过三十二亿恒河沙国土』，也是在讲种性上的差别
  • 空间横遍十方、时间竖穷三际，都属于经典的密法言说。
    空间横遍十方，时间竖穷三际，都属于经典的密法言说。
  • 如来座前二十菩萨『往昔皆与毘卢遮那如来共集善根』，讲的是他们在因地发心的因缘；他们已到毘卢遮那如来的法身世间，所以经文语言表达为生起如来座前二十位菩萨。
    他们已经到达毘卢遮那如来的法身世间
  • 经典中的『演说』分四种：语言音声、文字名相、身心觉受生起、诸法如实呈现；前两种是化身世间的演说方式，后两种分别是报身世间、法身世间的演说方式；四种总合即《法华经》『开示悟入』。
    这四种演说总合在一起，即《法华经》所言的『开示悟入』。
  • 四种演说中，依文字名相的演说可成为经典、穿越时空留给后人；其余三种要么依当下个体的直接听闻，要么依成就者的报身、法身世间，非凡夫大众普遍可领受。
    依文字名相的演说可以成为经典，可以穿越时空留给后人
  • 经典集结是成就者将报身、法身世间行法和成就转成化身世间的种种演说；密法言说和经典解读则是修行者将种种经典演说转到报身、法身世间行法实践的成就上去，即转到生命体验上去。
    也就是转到生命体验上去
  • 《世主妙严品》中与毘卢遮那共集善根的二十位菩萨，从一切法显相角度说，代表从生命本体如何生起一切法，是从生命最根本处深入微细生起演说；语言文字表达较慢，但身心觉知上实际是一瞬间到达一切法；语言文字是般若智慧的表现形式，成就无上正觉者必然有演说无上正觉生命体验的能力。
    修行者成就无上正觉，必然有演说无上正觉生命体验的能力。
  • 凡夫种性观察一切法没有那么微细，看不清从生命本体如何生起世间一切法；而《华严经》能用世间语言按生起次第把这个过程详细说清楚。
    而《华严经》却能用世间语言，把这个过程按照生起的次第详细说清楚。
  • 从本体到一切法呈现，凡夫地看是一瞬间完成，即一念；从华严行法角度是一劫；以此理解二十菩萨生起，它不是历史故事，不是十普菩萨离佛近一点、十别稍远、再远是四十二类围绕众；生起世间一切法、呈现一切境界是一瞬间完成，只是用语言文字描述时才如此依次。
    生起世间一切法，呈现世间一切境界，是一瞬间完成的
  • 整部《华严经》都在描述众生的生命成就；我们缺乏的是对生命显发的一切境界的认识；从毘卢遮那如来、从一切众生生命本体，首先生起二十菩萨围绕，再生起四十二类围绕众，以此方式描述一切法的呈现。
    整部《华严经》都在描述众生的生命成就。
  • 《世主妙严品》只讲呈现，具体行法理论在普光明殿演说；普光明殿和入法界两处合起来讲修行者如何从凡夫种性到妙觉位如来种性；菩提场会六品讲的是到达如来座前、生命本体时的成就显现。
    具体的行法理论是在普光明殿来演说的
  • 菩提场会六品告诉我们生命本来如此；学了普光明殿行法理论与入法界三会后再看会更明白；这里是修行者行法实践所要到达的地方，既是生起处也是成就处；《世主妙严品》中行法理论与行法实践隐秘其中，讲普光明殿时会说清。
    既是行法实践的生起处，也是成就处
  • 菩提场会作为行法实践的生起处，意味着众生自性中有生起乃至成就此一切法的欲求和能力；这种欲求和能力通过世尊成就、二十位菩萨生起、四十二类围绕众成就无量解脱门的形式呈现，可生起普光明殿四个阶段行法理论与入法界无量行法。
    众生自性中有生起乃至成就此一切法的欲求和能力
  • 二十位菩萨的具体属性表明菩萨不是笼统模糊的概念，而是能生起行法实践和生命体验的力量；这些经文从如来地普贤菩萨法界角度说，代表如来地无上正觉中的根本智行法属性，指向差别智行法，即具体的生命体验。
    而是能生起行法实践和生命体验的力量
  • 『无量功德』指报身世间无上正觉在生命体验中的呈现；诸佛如来无上正觉成就境界以菩萨道种智行法形式呈现在生命体验中；学到普光明殿等妙觉位普贤菩萨法界行法理论时才能完全明了。
    『无量功德』是指报身世间无上正觉在生命体验中的呈现
  • 二十位菩萨之后是四十类围绕众，每类十位代表共四百位；按过去人的分法按四位行法分类，十住位十类的第一类是十位等觉菩萨（如来座前十别菩萨），其后从执金刚神到主药神共九类，合共十类。
    十住位十类大众的第一类是十位等觉菩萨
  • 为何如此：《世主妙严品》讲生命本体本来具有的一切法呈现，每位众生都具足；从成就者角度，修行者从初发心到如来地整个行法过程中，初发心处就是如来座前的二十菩萨。
    修行者从初发心到如来地整个行法实践过程中，初发心处就是如来座前的二十菩萨
  • 华严行法十信位从如来座内十普菩萨生起的一切法开始，即从身心觉知一切法生起，经历住行向地四位行法，到等妙觉如来地，最终回到生命本体的一切法中，即回到身心觉知的一切法中。
    最终回到生命本体的一切法中，即回到身心觉知的一切法中
  • 普光明殿三个经首：十信位在普光明殿演说，经首在《如来名号品》；转到等妙觉位同在普光明殿，经首在《十定品》；妙觉位如来地究竟成就仍在普光明殿，经首在《离世间品》。
    经首在《如来名号品》
  • 普光明殿四个阶段行法理论与实践以『普光明殿』所代表的根本智为核心展开；别教菩萨住行向地四位行法是到达根本智无上正觉成就地必须的桥梁；普光明殿是生命中一切法所在处，亦是根本智所生一切法所在处。
    别教菩萨住行向地四位行法是修行者到达根本智无上正觉成就地必须的桥梁
  • 站在《世主妙严品》角度，如来座前二十菩萨是我们身心觉知一切法生起处，经四十位行法后又回到如来座前成就无上正觉，依然在身心觉知的一切法生起处；这是整个华严行法理论的核心。
    这是整个华严行法理论的核心
  • 四十二类围绕众的生起处就是如来座前二十菩萨的成就处；围绕大众四十类代表住行向地四位行法的四十位行法：十住位十类神众（执金刚神、身众神…主药神）；十行位（主稼神、主河神…主夜神、主昼神）；十回向位（阿修罗王、迦楼罗王…月天子、日天子）；十地位（三十三天王…大自在天王）。
    四十类围绕众生皆是我们生命中本自具足的，生起生命中的一切法。
  • 《入法界品》文殊在福城东大塔庙十方诸佛成就处演说普照法界修多罗，大海中一万诸龙发菩提心得不退转；『大海』是身心觉知的一切法，生生不息流转不停；凡夫众生流转生死、在大海中头出头没，指的就是在五蕴身六入处的一切法中。
    这个大海指的就是凡夫众生生命中的一切法，就在身心觉知的一切法中
  • 『诸龙』代表恶法习气；恶法习气能皈依自性觉悟、不再给生命带来束缚困扰时，即是文殊演说普照法界修多罗、一万诸龙皈依文殊发菩提心得不退转；修行者要能回到自性觉悟、在当下一切法中体验经典所说，这是福城东大塔庙一会的意义。
    修行者要能回到自性觉悟，回到当下的一切法中体验经典所说
  • 若没有文殊菩萨演说普照法界修多罗，生命中的恶法种子仍在生死海中头出头没；演说之后，生命中一切法包括恶法、生死染著法，都会变成成就无上正觉的智慧种子。
    生命中的一切法，包括恶法、生死染著法，都会变成我们成就无上正觉的智慧种子
  • 四十类四百位围绕众加座前两类二十位菩萨，合为四十二类四百二十位围绕众；这些是每个众生生命中本有的，凡夫地也不缺；《世主妙严品》中它们围绕世尊生起；修行者成就如来种性无上正觉时，身心觉知的一切法就成为如来地四十二类围绕众。
    当修行者成就到如来种性无上正觉时，身心觉知的一切法就会成为如来地的四十二类围绕众
  • 十住位十行位二十类围绕众都是神众：神代表生命力量，遇缘则显、无缘则隐，因只是力量，无形无相，故称神；因十住十行讲出世间行法、报身世间不共法的智慧成就，不遇缘不显相。
    虽然能生起作用，但是无形无相，所以称之为神
  • 十回向位十地位二十类围绕众都是王众：二位讲入世间道种智行法，王众代表生命中能生起应用、能做主统领一切法的因素；如阿修罗王、迦楼罗王，明了何为阿修罗、迦楼罗就知所代表的因素；十回向与十地代表能在世间显相的因素。
    王众代表生命中能够生起应用、能够做主统领一切法的因素
  • 讲身见边见及贪瞋痴慢疑，都是从总相上说，呈现时每种皆包含很多内容（贪有很多种，瞋有很多种）；『王』代表这一类中能做主的因素，再细分还有更详细类别。
    贪有很多种，瞋有很多种
  • 将四百二十位围绕众放在《世主妙严品》，表明如来种性身心觉知的一切法皆是清净世间一切法；这些种子不离凡夫世间一切法，即便凡夫世间身心觉知一切法也以此模式呈现；只是因为未证如来种性、未到如来座前，这些就是阿修罗王、迦楼罗王带来的身心困扰。
    这一切法就是这些阿修罗王、迦楼罗王带来的身心困扰
  • 到达如来座前的第一步：生起华严十信位行法、内在觉知模式行法，认识到身心觉知一切法既是成就无上正觉的发起处，也是行法实践的成就处；用《入法界品》语言即文殊菩萨从善住楼阁出，往诣人间，在福城东大塔庙往昔诸佛成就处演说普照法界修多罗；十信位行法一旦建立，身心觉知一切法包括恶法、生死染著法，都成为成就无上正觉的种子。
    十信位行法一旦建立，意味著从这里开始，我们身心觉知的一切法
  • 智慧种子从发起到如来种性成就地，需经十住、十行、十回向、十地位菩萨道种智行法和等觉位普贤菩萨法界行法；种子发起即文殊演说普照法界修多罗，一万诸龙发菩提心得不退转；经四位行法到等妙觉如来地时，一万诸龙才从发菩提心真正到达如来座前，成为如来地无上正觉围绕众。
    这时一万诸龙才从发菩提心真正到达如来座前
  • 『四十二』这个法数，是从无上正觉成就者角度看待身心觉知一切法，与凡夫种性看法不同；凡夫种性即便在清净世间，身心觉知一切法依然是生死法。
    凡夫种性即便在清净世间，身心觉知的一切法依然是生死法
  • 一定要生起内在觉知模式的行法，以正知见、正思惟为核心，才能进入华严行法；要在身心觉知一切法中建立自己的智慧行法，这就是四十二类围绕众所表达的意义。
    要在身心觉知的一切法中，建立自己的智慧行法，这就是四十二类围绕众所表达的意义。
  • 执金刚神一类共十位，经文说他们『皆于往昔无量劫中恒发大愿，愿常亲近供养诸佛；随愿所行，已得圆满，到于彼岸……一切如来所住之处，常勤守护』；要看身心觉知一切法中执金刚神那个因素如何以怎样行法模式转变到如来座前成为围绕众，这段经文把往昔因缘说清楚；其他类说得简略。
    皆于往昔无量劫中恒发大愿，愿常亲近供养诸佛

            行法精进不等于苦行

            很多修行者讲行法精进，以为是苦行，把简单的三更睡五更起当成精进。

            这是凡夫外道的精进；佛教精进一定与智慧增胜同时展开，苦行而无智慧增胜不算行法精进。

            苦行的同时，如果没有伴随智慧增胜，就算不上是行法精进
            一法要从多方面说清才是行法精进

            比如讲生死、出离生死，就必须弄清什么是生死、什么是出离生死、什么是出离生死的行法实践、出离生死的标准和身心觉受如何等。

            这些不是固定简单的概念，要从多个方面准确说明，准确说明的过程就是行法精进。

            比如讲到生死、出离生死，就必须要弄清楚什么是生死，什么是出离生死

            怎么用

            怎样到达如来座前（让身心觉知的一切法成为成就无上正觉的种子）
            1. 第一步生起华严十信位行法、内在觉知模式行法
            2. 认识到身心觉知一切法既是成就无上正觉的发起处，也是行法实践的成就处
            3. 以正知见、正思惟为核心（即文殊的演说：开示悟入）
            4. 此后恶法、生死染著法都成为无上正觉的种子；再经住行向地与等妙觉位到如来座前
            修行者如何到达如来座前？第一步是生起华严十信位行法，生起内在觉知模式的行法
            怎样把贪瞋痴慢习气转变成智慧种子
            1. 依《世界成就品》世界成就十种事一百个方面为基准
            2. 以贪瞋痴慢中的一法为种子
            3. 以四智十方为演说模式
            4. 对这一法生起觉知观察和思惟体验，生起种种分别、选择和判断，最终获生命解脱与无上正觉

            怎样确定具体的行法精进
            1. 从十个方面考量一法
            2. 思惟：种性如何，精进的形式、因缘、显相如何
            3. 什么是退转、什么是升进、什么是安住
            4. 把这些综合在一起确定具体精进行法

            怎样读流水文

            3. 综合考量，按各方的属性（如东方大圆镜智、南方平等性智）解读

            怎样让觉知思惟从粗相到无上智慧

            3. 从粗相到细相，从细相到微妙相，不断升进
