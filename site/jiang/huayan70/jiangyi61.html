要点讲《入法界品》五十三参中第四回向位师子频申比丘尼、第五回向位婆须蜜多女、第六回向位鞞瑟胝罗居士、第七回向位观自在菩萨、第八回向位正趣菩萨，说明善知识放光的变化、密法言说的读法，以及行法如何从三贤位转入金刚种性智慧行法。

概述

讲者先把第四回向位师子频申比丘尼与第五回向位婆须蜜多女成对讲：比丘尼代表已得梵行清净、示现在世间一切法中，世间女代表世间一切法本自清净，二者总合到第六回向位。接着强调五十三参的善知识不是外在个体，而是根本智到具体生命体验过程中的一个个阶段，读经要做『体验性诠释』，以准确体验为判断标准。讲婆须蜜多女时，解释『庄严』『夜神』『城北』，并驳斥『婆须蜜多女示现恶法』的误解，引魔王三女、《维摩诘经》天女『求女人相了不可得』为证。第六回向位鞞瑟胝罗居士成就『不般涅槃际菩萨解脱』，讲者解释三种涅槃、『以自为因』、孔子『仁』，并把『开栴檀座如来塔门』读作与龙树入龙宫、开南天铁塔同等的密法言说。第七回向位观自在菩萨与第八回向位正趣菩萨成对，善知识放光越来越详细，对比普光明殿法数（十千、百万、百万亿）与《入法界品》故事化演说的差别；正趣菩萨『以足按地』于『娑婆世界轮围山顶』，说明金刚种性智慧的成就处就在娑婆世界一切法中。

结构

第四回向位师子频申比丘尼

  • 十回向位精进修阶段第一位，与各行法位次对齐
  • 比丘尼＝已得梵行清净示现在世间一切法中；师子频申的含义
  • 无上正觉成就相逐位微细
  • 胜光王、日光园、满月大树、放光的解读
  • 三十种演说；善知识不是外在个体；意生身
  • 还没有到摩竭提国菩提场的成就模式

第五回向位婆须蜜多女

  • 无量功德藏回向；婆须蜜多＝纯粹世间法世间相
  • 险难国宝庄严城；『庄严』的定义与建筑音乐的类比
  • 城北自宅；东方北方与四智；夜神＝智慧深密
  • 城中人两种说法；婆须蜜多女非示现恶法；《维摩诘经》天女
  • 离贪欲际解脱；放光的对比；金刚种性的最低位次

第六回向位鞞瑟胝罗居士

  • 不般涅槃际菩萨解脱与三种涅槃
  • 居士身份＝比丘尼与世间女总合
  • 以自为因；孔子『仁』
  • 开栴檀座如来塔门＝龙树入龙宫、开南天铁塔的密法言说

第七回向位观自在菩萨

  • 菩萨大悲行门；五位菩萨；两位住山的善知识
  • 放光描述趋于详细；法数十千、百万、百万亿
  • 普光明殿（理论）与入法界品（实践）的演说差别
  • 观自在菩萨的能力是逐步积累而来

第八回向位正趣菩萨

  • 不退转阶段与一生补处阶段无间隔
  • 放光范围、『娑婆世界轮围山顶』、『东方虚空』
  • 以足按地；山的对应；种性决定娑婆世界还是极乐世界

主要观点

  • 第四回向位至一切处回向是十回向位精进修阶段中的第一位行法，是十波罗蜜中第四位精进波罗蜜，与第四住位弥伽长者、第四行位明智居士、第四地位普救众生妙德夜神、第四等觉位善知众艺童子对齐。原文与第四住位弥伽长者、第四行位明智居士、第四地位普救众生妙德夜神、第四等觉位善知众艺童子对齐
  • 第四回向位善知识师子频申比丘尼是五十三参中唯一一位比丘尼，出家身亦女身，代表已得梵行清净，示现在世间一切法中。原文第四回向位善知识师子频申比丘尼是五十三参中唯一一位比丘尼，是出家身，亦是女身
  • 『师子频申』是指不但具备无上正觉的智慧力量，亦具备无上正觉的成就相，能入世间一切法中，降伏生死烦恼魔怨。原文能入世间一切法中，降伏生死烦恼魔怨
  • 无上正觉成就相随行法升进逐渐微细和拓展：第七住位『具大人相坐真金座』开始具备；初行位『顶有肉髻，皮肤金色，胸标卍字，七处平满』；第八行位具『二十八种大人之相』；第九行位『其身毛孔恒出妙香』；初回向位名『优钵罗华长者』即『青莲华长者』。这说明自性智慧带来的生命解脱与无上正觉行法体验越来越微细清晰、广大庄严，从简单外显的大人之相转入内在本质与无上正觉同等的大人之相。原文越来越从简单外显的大人之相转入到内在本质与无上正觉同等的大人之相
  • 从入世间成就说，第四回向位的『比丘尼』超越十住十行位的五位比丘，更靠近世间法；从出世间成就说，此『比丘尼』超越一切世间，于一切法中得梵行清净。原文此『比丘尼』则超越一切世间，于一切法中得梵行清净
  • 第五回向位婆须蜜多女是五十三参中唯一一位世间女，代表世间一切法本自清净，去除了一切出世间清净法表相。原文代表世间一切法本自清净，去除了一切出世间清净法表相
  • 师子频申比丘尼与婆须蜜多女成对出现：从比丘尼到世间女，是从报身世间智慧指向入世间一切法；二者总合在一起到达第六回向位，成就菩萨所得不般涅槃际解脱，非世间非出世间，非解脱非不解脱。原文二者总合在一起到达第六回向位，成就菩萨所得不般涅槃际解脱，非世间非出世间，非解脱非不解脱
  • 师子频申比丘尼住『轮那国迦陵迦林城』：『轮那』指生命中的一切法无有边际、流转不息；『迦陵迦林城』指充满无量纷争之地。原文『迦陵迦林城』是指充满无量纷争之地
  • 『胜光王』是自性根本智，『日光园』是根本智所生一切法的普遍存在（亦即生命中的一切法普遍存在），『师子频申比丘尼』是自性根本智带来的总体生命体验，三者非一非异。原文三者非一非异
  • 『在胜光王之所舍施日光园中说法利益无量众生』一句，包含了以往诸参的种性成就、住处成就、说法成就等因素：第七住位休舍优婆夷为『妙圆光王』夫人，住『圆满光大城城东普庄严园林』，发菩提心得无生忍；第十住位慈行童女为师子幢王之女，住『师子奋迅城毘卢遮那藏殿』；第八行位大光王住『妙光城』见世间一切法皆悉严净；第九行位不动优婆夷住『安住王都』，身是童女、父母守护；第十行位遍行外道住『无量都萨罗大城』示现同类众生说无量法。原文包含了以往诸参中的种性成就、住处成就、说法成就等因素
  • 以上诸参的细节意味着行法实践是不断积累的过程，是知识、经验和体验不断进步的过程；无上正觉并非一蹴而就，不是靠简单重复、省时省力的民间信仰可以到达。原文无上正觉并非一蹴而就，不是靠简单重复省时省力的民间信仰可以到达
  • 『满月大树』是生命体验的总体呈现，即以『自我』因素为核心的『个体生命』中一切法总合为一的呈现；『放大光明』指觉知观察思惟等身心觉受，是从根本智带来生命体验的角度说；有情众生时常保持对一切法的觉知观察，用经典语言来说就是『满月大树』放大光明。原文有情众生时常保持对一切法的觉知观察，用经典语言来说，即『满月大树』放大光明

  • 善财童子『见』日光园中一切庄严，所言『如是皆从师子频申比丘尼了法如幻集广大清净福德善业之所成就』，意味着『自我』因素对生命中一切法的觉悟与明了。原文意味著『自我』因素对生命中一切法的觉悟与明了
  • 师子频申比丘尼为『净居天众』演说『无尽解脱法门』，直到为『执金刚神』演说『金刚智那罗延庄严法门』，共三十种，表明第四回向位能够在遍一切处的一切法中生起，为一切众生演说种种不同法门；『演说』是以智慧力生起对一切法的如实知、如实体验，善财童子『见』种种演说，即『自我』因素明了生命中的一切法如何生起、如何到达身心体验。原文一共三十种，表明第四回向位能够在遍一切处的一切法中生起
  • 五十三参善知识并非外在独立的个体，而是从自性根本智到具体生命活动与生命体验过程中的一个个阶段，是根本智力量的具体呈现，每个阶段皆带来不同的生命体验、生起无量法；师子频申比丘尼『遍坐一切诸宝树下大师子座』演说无量法，就是其中一个阶段。原文五十三参善知识并非外在独立的个体，而是从自性根本智到具体生命活动与生命体验过程中的一个个阶段
  • 善财童子入法界行法，是修行者以『自我』因素生起行法实践，如实明了和体验生命中的一切法如何生起、如何一步步到达身心觉受；身心觉受越靠近生命解脱与无上正觉，所具备的『无上正觉大人之相』越坚固完善，自所住处越殊妙庄严。原文身心觉受越靠近生命解脱与无上正觉，用经典语言来讲，即所具备的『无上正觉大人之相』越坚固完善
  • 修行者是以这种方式对经文生起体验性的诠释，将五十三参转变为不断升进的行法实践；准确体验是修行者自知自觉『证得』任何一位行法必须的判断标准。原文准确体验是修行者自知自觉『证得』任何一位行法必须的判断标准

『庄严』的两种层次：表相庄严与智慧思想的庄严

讲者说，通过眼耳鼻舌身，人能体验高大精美的建筑、富丽堂皇的亭台楼阁、优美宏大的音乐、图画所带来的『庄严』；而这些建筑、音乐、图画背后精巧的思想设计，以及严密深妙的思想理论体系，也能带来内在的庄严体验。

智慧、思想、理论带来的庄严更加深密持久，不会随时间和表相改变；佛经里诸佛世界的庄严就是在智慧应用与生命体验中呈现的这种稳定可靠的庄严。原文通过眼、耳、鼻、舌、身能体验外在高大精美的建筑、富丽堂皇的亭台楼阁、优美宏大的音乐、图画所带来的『庄严』

世间一切法即魔所在处，也是无上正觉成就处

世尊坐菩提树下成就无上正觉时，魔王的三个女儿极爱、悦彼、适意前来侵扰；世尊降伏了魔怨，最终成就无上正觉。

婆须蜜多女（世间女）不是示现恶法；一切法平等、无女人相

《维摩诘所说经·观众生品》中，文殊菩萨带舍利弗等参访维摩诘，一位天女闻法现身。舍利弗尊者问：你为什么不转女身？天女回答：我十二年来寻求女人相而了不可得，要转什么呢？

讲者说，同样是『山』，经典里须弥山、轮围山代表凡夫种性的身心觉知一切法；妙峰山、楞伽山代表证诸法空得无生忍时的身心觉知一切法；补怛洛迦山代表第七回向位成就金刚种性智慧时；而第八回向位正趣菩萨来到的『娑婆世界轮围山顶』则从入灭尽定行法、从当下身心觉知的一切法中生起行法实践的角度说。

名字不同，但所代表的都是身心觉知的一切法，只是行法阶段不同；不可把这些山当作固定处所。原文须弥山、轮围山代表凡夫种性的身心觉知一切法

怎么用

如何读《入法界品》的善知识，使之成为行法实践而不是故事原文修行者是以这种方式对经文生起体验性的诠释，将五十三参转变为不断升进的行法实践
  1. 不把善知识看作外面独立存在的个体，而看作根本智到具体生命体验过程中的一个阶段
  2. 把善财童子看作『自我』因素，以自觉悟力如实明了生命中一切法如何生起
  3. 对经文生起体验性的诠释，把五十三参转变为不断升进的行法实践
  4. 以准确体验作为自知自觉『证得』某位行法的判断标准
  5. 结合普光明殿行法理论与五十三参经文细节读，不能不足，也不能超过
怎样把握善知识放光所显示的行法升进原文修行者必须通过不同行法位次之间的经文对比，才能准确解读这种演说所表达的意义
  1. 比较不同回向位善知识放光的范围（只照自所住处还是更广）
  2. 比较经文对放光描述的详略
  3. 比较放光是否与善财的生命体验相关
  4. 对照普光明殿法数的递增（十千、百万、百万亿）
怎样证得金刚种性、大涅槃原文要能以『自我』因素为核心生起生命中的一切法，即『以自为因』生起一切法
  1. 以『自我』因素为核心生起生命中的一切法
  2. 『以自为因』，不以『自我』生命之外的其他力量为因
  3. 完全自内显发、主动自觉生起
  4. 先能如实知、如实管理一切法，再以智慧力自觉出生一切法
怎样对待眼耳鼻舌身一切法（世间法）以求解脱原文行法实践的目标并非息灭这一类法生起的力量，而是以智慧力如实知、如实管理此一切法
  1. 不像凡夫那样贪爱乐著
  2. 不像二乘与共法别教那样进入无想定、断灭见，远离一切法
  3. 以智慧力如实知、如实管理此一切法，使其生起的力量转为生命解脱与无上正觉现前的力量
  4. 以此一切法为无上正觉成就处
