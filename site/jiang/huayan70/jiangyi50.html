华严七十讲

第五十讲

要点讲第三参末段与第四参弥伽长者（第四住位生贵住）：戒的两个核心、自在城与轮字庄严法门、菩提心如何在行法中起作用、弥伽长者下师子座与放光、妙音陀罗尼与名相言说，以及『空』要当动词、自我因素不可息灭。

概述

讲者先说前三位善知识皆比丘相，代表以出世间智慧进入五十三参，并批评民间信仰把解脱寄托于异身异时异处。接着讲善住比丘推荐弥伽长者，说明『戒』的两个核心是梵行清净与行法精进，并解读达里鼻荼、弥伽、自在城等名号。第四参弥伽长者于市肆中坐师子座说『轮字庄严法门』，讲者用英文二十六个字母等例子解释『轮字』，强调概念准确是次第清晰与系统完备的基础。随后详谈发菩提心：它不是突发奇想或投资性发心，而是自内主动进入启发自性觉悟的生命状态，并从十信位说明菩提心如何通过善用心、善思惟、行法检验与反馈起作用。弥伽下师子座礼拜善财、面门放光、说得妙音陀罗尼，引出名相言说在见性位后不可缺少、『空』要当动词、自我因素不可息灭而只息灭其束缚影响、八部天众即生命中的恶法种子须如实见如是演说。

主要观点

  • 前三位善知识皆是比丘，代表修行者以出世间智慧才能进入五十三参行法；出世间行法模式即梵行清净、行法精进，以经典语言即皈依佛法僧，亦即十住位『天帝释请佛入妙胜殿』。
    五十三参前三位善知识皆是比丘，代表修行者以出世间智慧才能进入五十三参行法。
  • 行法实践的目标是把天帝释所代表的『自我』因素，从十信十住之前以我身、我见为主的作用模式，转变到皈依自性觉悟的作用模式，最终以梵行清净和行法精进到达如来地无上正觉。
    转变到皈依自性觉悟的作用模式
  • 法界不在别处，就在身心觉知的一切法，乃至在以我身我见生起的众生地种种烦恼中；入法界行法以自我参与为主体、梵行清净行法精进为模式、一切法的普遍存在为成就处。
    入法界行法是以『自我』参与为主体，以梵行清净、行法精进为模式
  • 民间信仰是世间法：因为它不能解决当下生命解脱的问题，把生命解脱与无上正觉寄期望于异身、异时、异处的来生来世，寄希望于环境改变而非自身改变。
    将生命解脱与无上正觉寄期望于异身、异时、异处的来生来世
  • 前三位善知识的行法：德云比丘住胜乐国妙峰山顶，在别山上徐步经行；海云比丘住海门国十二年，常以大海为境界，千二百岁受持普眼法门；善住比丘住楞伽道边海岸聚落，于虚空中来往经行。
    善财童子见德云比丘『在别山上徐步经行』
  • 德云比丘『在别山上徐步经行』指昼夜六时思惟妙法，从不离一切法而超越一切法角度说；海云比丘常以大海为境界生起广大觉知观察思惟，与之同等意义但针对大海；善住比丘的来往经行亦指昼夜六时思惟妙法，但已是从得究竟无碍智慧光明、知一切世界一切法的角度说。
    虽然善住比丘的『于虚空中来往经行』亦指昼夜六时思惟妙法，但已经是从得究竟无碍智慧光明
  • 与后面行法相比，前三位因还没入于一切法中，仍是从总持力的角度、从不离一切法而安住出世间梵行清净的角度说。
    还是从总持力的角度、从不离一切法而安住出世间梵行清净的角度说
  • 佛教讲的神通是大神通，指以智慧力入一切法中无有障碍，能降伏生死烦恼，出三界得生命解脱；世间人的业用神通在生死法中不出三界。佛教并非没有业用神通，要到十地位，以金刚种性智慧力生起，此种业用神通不在生死法中，不受一切法束缚。
    要到十地位，以金刚种性智慧力生起，此种业用神通不在生死法中，不受一切法束缚
  • 『普速疾供养诸佛成就众生无碍解脱门』即前面的『菩萨无碍解脱门』，是从总持力角度说；后面『如诸菩萨持大悲戒』乃至『离垢戒』等二十种戒是从具体显现角度说，戒是菩萨无碍解脱的具体表现。
    『戒』是菩萨无碍解脱的具体表现
  • 菩萨行法中的『戒』有两个核心：梵行清净、行法精进，任何与这两方面相违背的皆是犯戒。
    任何与这两方面相违背的皆是犯戒
  • 菩萨忏悔与常人不同：不少人对某事忏悔，每天坐卧不宁、寝食难安，以为这是真心忏悔，但若忏悔本身破坏了梵行清净与行法精进，这种忏悔亦是犯戒；菩萨忏悔是依梵行清净而如实知，保证以后不再造。
    如果忏悔本身破坏了梵行清净与行法精进，这种忏悔亦是犯戒
  • 『达里鼻荼』四十华严译『达逻比咤』，是根据『a』的不同发音造成：读『阿』音即达逻比咤，读『奥』音即达里鼻荼；如『阿弥陀佛』的『阿』、『楞伽』的『伽』也有不同读音，不是这样正确而那样不正确。
    读『阿』音即『达逻比咤』，读『奥』音即『达里鼻荼』
  • 第四住位生贵住善知识弥伽长者在十波罗蜜行法中主精进波罗蜜；『达里鼻荼』指自在丰饶之地，生命一切法生生不息即自性智慧不断生起，契合生贵住；『弥伽』指能伏，有能力降伏世间诸法束缚影响；『长者』六十华严译『良医』。
    第四住位生贵住善知识弥伽长者在十波罗蜜行法中主精进波罗蜜
  • 『自在』指基于究竟无碍智慧光明、基于对一切法如实知，于一切法中来往自由无障碍的生命解脱，不是基于欲望自由、衣食富足应有尽有，或如在荒野自由奔跑的动物。
    非基于欲望自由、衣食富足应有尽有或如同于荒野中自由奔跑的动物一样
  • 城名『自在』六十华严译『咒药』，四十华严译『金刚层』；『咒』即智慧，『金刚』也指智慧，特指能到达世间一切法乃至普贤菩萨法界的智慧，十回向位与十地位上首菩萨分别为金刚幢与金刚藏；弥伽长者以智慧力降伏一切法的束缚与影响，以梵行清净、智慧增胜、行法精进为自在丰饶之自所居处。
    弥伽长者以智慧力降伏一切法的束缚与影响
  • 名字解读规则：一般来说名字没译成汉语，可按隐秘智慧的角度解读；译成汉语，可按行法实践显现的角度解读。如文殊师利（不翻）代表智慧、普贤（翻）代表行法；干陀诃提菩萨可解为智慧精进、常精进菩萨可解为行法实践精进；阿弥陀佛与无量寿佛亦如此。
    如果这些名字没有译成汉语，可以按隐秘智慧的角度来解读，如果译成汉语，可以按行法实践显现的角度来解读
  • 第四参经文结构九段：闻法信行恋德礼辞；前法契入一心正念法光明法门；至自在城见弥伽长者于市肆中师子座上说轮字庄严法门、十千人众围绕；善财礼拜陈述发心、征十二问；长者确认已发菩提心，下师子座礼拜、散华、赞叹；长者面门放光，众生闻法皆发菩提心得不退转；长者升座说得妙音陀罗尼门，能分别知大千世界众生语言；说自法门及精进行法；推荐第五位解脱长者。
    长者升座说得妙音陀罗尼门，能分别知大千世界众生语言
  • 五十三参每一参长短不同，但总体遵循结构：亲近善知识、恭敬闻法、起善思惟、依教奉行。善财不是直接从一位善知识到下一位，中间有依教奉行即『证入』善知识行法的过程；生起行法前『礼辞善知识』，代表从听闻转变到自内生起善思惟、自觉生起行法实践。
    亲近善知识、恭敬闻法、起善思惟、依教奉行
  • 『其足』的『其』指第三住位善住比丘；『法光明法门』即『普速疾供养诸佛成就众生无碍解脱门』『菩萨无碍解脱门』『究竟无碍智慧光明』；从『深信趣入』到『于一切佛众会道场心无所著』是『一心正念法光明法门』的细节。
    『法光明法门』即『普速疾供养诸佛成就众生无碍解脱门』
  • 『渐次南行至自在城，求觅弥伽』指善财虽具足前一位行法，但与下一位善知识住处还有距离；善知识不是靠直观表浅观察体验获得，而要经历观察与思惟，在『求觅』中获得。
    善知识不是靠直观的、表浅的观察体验即可获得
  • 『其人于市肆中，坐于说法师子之座』指弥伽长者能于普遍存在的一切法中生起智慧，而其自身坚固不动。
    弥伽长者能够于普遍存在的一切法中生起智慧，而其自身坚固不动
  • 前三位善知识住处：德云住妙峰山顶超越一切法，海云住海门国面向一切法，善住住海岸聚落毗邻一切法，由山顶逐渐到海边；第四位住市肆中已进入一切法中，但坐师子座与市肆中人不同，自所居处远离世间；『自所居处』即修行者报身世间所在处，十住位总体皆以出世间行法为核心。
    善知识住处从山顶逐渐到达海边，离大海越来越近。
  • 『十千人众所共围绕』指弥伽长者所成就的行法可以随缘显现；『轮字庄严法门』即末后所讲的『菩萨妙音陀罗尼光明法门』。
    『十千人众所共围绕』是指弥伽长者所成就的行法可以随缘显现
  • 五十三参中第四等觉位善知识善知众艺童子，恒唱持『四十二字母』为菩萨解脱门，与第四住位对应，都是以智慧力入一切法中得究竟解脱；弥伽长者强调的是如何从根本智所在处生起智慧入一切法中，如实知、如实演说一切法。
    五十三参中的第四等觉位与此第四住位行法对应
  • 智慧应用需要概念准确、次第清晰、系统完备；概念准确是基础，轮字是智慧应用最基本最核心的元素；只有基本元素准确无误，才能构建周密完备的思想理论体系；弥伽所演说的轮字庄严法门是生起所有智慧应用的核心元素，以十千人众形式在一切法中显现。
    只有基本元素准确无误，才能构建起周密完备的思想理论体系
  • 善财此时『已发阿耨多罗三藐三菩提心』是在前三位行法菩提心的基础上成就的；虽问法核心仍是『云何学菩萨行、云何修菩萨道』，但发菩提心的内容和形式已与福城东大塔庙时完全不同；从『云何流转于诸有趣常不忘失菩提之心』到『云何得智慧力，于一切法悉能决定分别其义』共十问，皆依第四住位两个问题而生。
    发菩提心的内容和形式已经和福城东大塔庙处时完全不同
  • 善财的这些问题既是第四住位行法的发起处，亦是这一位行法的成就处；它们要回答的，就是弥伽长者的『妙音陀罗尼光明法门』或『轮字庄严法门』所成就的。
    善财童子的这些问题既是第四住位行法的发起处，亦是这一位行法的成就处
  • 善知识确认善财已发菩提心，意味着必须依发菩提心才能生起当位行法，这种『确认』在五十三参中经常出现。
    善知识确认发菩提心，意味著必须依发菩提心才能生起当位行法
  • 善财发菩提心从福城东大塔庙听闻文殊演说诸佛无量法开始，即从普光明殿十信位依根本智力量开始，具体是从对一切法生起觉知观察、生起善用心、善思惟开始。
    善财童子发菩提心是从福城东大塔庙听闻文殊菩萨演说诸佛无量法开始的
  • 弥伽长者代表根本智显现，能坐师子座演说妙法，十千人众是具体的差别智显现；确认善财发菩提心，意味着必须以根本智的力量才能到达根本智成就处，才能生起弥伽长者的行法。
    必须以根本智的力量才能最终到达根本智成就处
  • 发菩提心是修行者基于对生命解脱与无上正觉的欲求，主动进入启发自性觉悟的生命状态；这像发起诚实善良之心，不是对外的欲求，出于生命自身的欲求；它会带来清净、稳定、专注、持久的觉悟力，菩提心力量贯穿每一位次行法。
    『发菩提心』会带来清净、稳定、专注、持久的觉悟力。
  • 善财五十三参是以这种觉悟力在自我因素生起的一切法中发起行法实践，即从普光明殿初住位『天帝释迎佛入妙胜殿』开始发起行法实践。
    亦即从普光明殿初住位的『天帝释迎佛入妙胜殿』开始发起行法实践
  • 若自认已发菩提心，却不能皈依自性觉悟，不能深入经藏、闻法欢喜、起善思惟、依教奉行，不能体会清净乃至持久的觉悟力，这种发心大部分只是突发奇想，非真正发菩提心。
    这种『发菩提心』大部分只是突发奇想
  • 有一种『发菩提心』只是基于民间信仰、宗教的投资性发心，目的是以简便省力快捷方法，甚至简单直接的钱财布施，来获得最大究竟的解脱回报，这非佛教所言发菩提心。
    以简便、省力、快捷的方法，乃至以简单直接的钱财布施，来获得最大究竟的解脱回报
  • 别教行法阶段会有『为生命解脱与无上正觉而发菩提心』的理念，但需明了：从发菩提心到生起行法实践本身即生命解脱与无上正觉，并非在行法实践之外；若认为解脱还要依赖他人、从外而得、异身异时异处获得，亦非佛教所言发菩提心。
    『发菩提心』乃至『生命解脱与无上正觉』并非在行法实践之外
  • 发菩提心作为以智慧力自觉发起对一切法如实知、如实体验的力量，在《华严经》中随处可见：菩提场会世尊成就无上正觉、四十二类大众围绕、最终以普贤菩萨生起世间一切法；普光明殿四个行法阶段文殊演说一切法普遍存在并生起住行向地；《入法界品》世尊在逝多林本会以文殊智慧生起善财五十三参。
    『发菩提心』作为以智慧力自觉发起对一切法如实知、如实体验的力量，在《华严经》的演说中随处可见
  • 菩提心在行法实践中的呈现，简单说即主动自觉以清净心对一切法生起关注，生起善用心、善思惟，深入经藏，依教奉行。
    主动自觉以清净心对一切法生起关注，生起善用心、善思惟，深入经藏，依教奉行
  • 十信位中，文殊菩萨在《如来名号品》《四圣谛品》演说一切法种种名号，名号包含对一切法的体验、分别、选择和判断，是修行者发菩提心的最初表现，首先要对一切法生起关注与觉知观察；文殊的演说针对人天众生能对一切法生起分别选择判断、分辨生死善恶的特质。
    『名号』包含了对一切法的体验、分别、选择和判断，此即修行者发菩提心的最初表现

    在十地位以后的行法中，菩萨以种种『如是思惟』转变到行法实践
  • 针对一法可有无量思惟方式，但只有一种符合生命解脱与无上正觉，是修行者所要建立的；修行者将这种如是思惟转变成行法实践和生命体验，令解脱与无上正觉现前。
    在这些思惟方式中却只有某一种方式符合生命解脱与无上正觉
  • 如是思惟的过程即对一切法生起分别、选择、判断的过程，从对一切法生起关注、从直观表浅零散的体验、从最初一切法『名号』生起开始，即智慧生起、显现的过程，亦即菩提心生起作用的过程。
    亦即菩提心生起作用的过程
  • 若行法实践带来的不是解脱与无上正觉的生命体验，必须回到善用心、善思惟阶段反思调整：为什么前一次实践没有带来；通过不断调整、实践、反馈，把直观表浅乃至本能的体验转变到解脱与无上正觉的体验。
    通过这样不断地调整、实践、反馈

    行法实践既是发菩提心、善用心、善思惟的呈现，亦是对此的检验

    『十万亿佛土』即娑婆世界与极乐世界之间的距离，这个距离要靠行法实践、种性改变才能跨越。
    善财与善知识何时合为一体

    第五十二参善财在普门国参文殊，文殊遥伸右手过一百一十由旬摩善财顶而自不现身；第五十三参善财在如来座前参普贤，自见其身入普贤身。其余诸参中善财入善知识身，皆是在善知识加持下。

    只有最后两参才表示善财与文殊、普贤等同，到如来种性的根本智成就地。

    意味著善财童子成就文殊菩萨圆满智慧，与文殊菩萨等同
    自性放光 vs 菩萨放光

    普光明殿四位行法中，世尊代表自性本体，时时处处可放光（或放两足光，或放双膝光）；而十住十行位的十方云集菩萨皆不放光，十回向位的十方云集菩萨即可放光。

    放光有广义（自性放光，一切众生皆有）与狭义（菩萨以差别智合会根本智的成就）之分；弥伽长者的放光属前者的角度。

    而菩萨在差别智行法中，并非时时处处可以放光
    福城东一万诸龙发菩提心与此处龙神梵天发菩提心的差别

    文殊在福城东大塔庙演说时，大海中一万诸龙发菩提心得不退转，诸龙与文殊没有交流，内容也不具体；此处龙神乃至梵天来到弥伽之所，弥伽以方便为其开示演说轮字品庄严法门。

    前者是从根本智生起一切法的原则性角度；后者是从根本智生起实际应用的角度。

    而此处『诸龙神等乃至梵天』不但『来至』弥伽长者所，弥伽长者亦以方便
    世尊授记中的『如实知之』『自知不受后有』

    世尊常给弟子授记：『梵行已立，所作已办，不受后有，如实知之』，另一句是『自知不受后有』。

    说明修行者确切到达某一位次时必然自知自觉；证阿罗汉时若自己不自知、不能领受解脱，就是断灭见。

    修行者确切到达某一位次的行法成就时，决定能够自知自觉

    怎么用

    怎样参访并升进到下一位善知识（五十三参每一参的通用做法）
    1. 亲近善知识
    2. 恭敬闻法
    3. 起善思惟
    4. 依教奉行：对善知识所教生起行法实践，即『证入』善知识行法
    5. 生起行法前『礼辞善知识』，从听闻转变到自内生起善思惟、自觉生起行法实践
    6. 在『求觅』中通过观察与思惟找到下一位善知识
    亲近善知识、恭敬闻法、起善思惟、依教奉行
    菩提心在行法实践中如何起作用、如何调整行法
    1. 主动自觉以清净心对一切法生起关注
    2. 通过名号生起善用心，转入报身世间
    3. 起善思惟，作出符合生命解脱与无上正觉的『如是思惟』
    4. 转变为行法实践与生命体验
    5. 若体验不符，回到善用心善思惟反思：为什么前一次实践没有带来解脱体验
    6. 不断调整、实践、反馈
    必须要回到善用心、善思惟阶段做出相应的反思和调整
    怎样判断自己是不是真的发了菩提心
    1. 能否皈依自性觉悟
    2. 能否深入经藏、闻法欢喜、起善思惟、依教奉行
    3. 能否体会清净乃至持久的觉悟力
    4. 若不能，多半只是突发奇想或投资性发心
    如果修行者自认为已经『发菩提心』，而却不能做到皈依自性觉悟
    怎样证自性空、诸法空（如何自检）
    1. 必须在一切法中、在自我因素参与中证得
    2. 先生起诸法
    3. 观察自己是否受诸法束缚和影响
    4. 受束缚影响则诸法不空，不受则诸法空
    要能生起诸法，然后观察自己是否受到诸法的束缚和影响
    怎样解读经典中的人名、地名（是否翻译）
    1. 名字没有译成汉语：按隐秘智慧的角度解读
    2. 名字译成汉语：按行法实践显现的角度解读
    3. 例：文殊师利（不译）代表智慧，普贤（译）代表行法
    如果译成汉语，可以按行法实践显现的角度来解读
