第四讲

要点概述魏晋南北朝至隋唐中国佛教的学派与宗派（三论、地论、涅槃、净土、禅、法华、华严、法相唯识），详述华严宗祖师年代、七处八会/七处九会与李通玄十处十会，并介绍天台四教与华严五教的判教。

概述

讲者先说鸠摩罗什时代儒释道互相提问辩论、促进各自思想建立，历史人物鲜活，宗派之间常是『井水河水』关系，思想有力量并转为世间行为。随后区分学派与宗派（宗派须有完整理论体系与独特行法），依次简介三论宗、地论宗、涅槃宗、净土宗、禅宗、法华宗（天台宗）的创立者、根本经论和年代。接着较详细地讲华严宗：杜顺、智俨、法藏、澄观四位祖师及李通玄的生卒年与相互关系，智俨判六十华严为七处八会，澄观判八十华严为七处九会，李通玄则提出十处十会。又说明了解祖师时代与经典背景对理解其思想的重要。最后介绍判教：天台『藏通别圆』四教，华严『小始终顿圆』五教（源自杜顺五教止观），并以法藏曾在玄奘译经院听唯识不相应而转学华严作结。

主要观点

  • 罗什时代的许多问题并非只针对佛教，儒、释、道三家互相提问、站在各自立场辩论，对各自思想体系的建立起积极作用，涌现慧远、僧肇、道安及后来的净影师、嘉祥师等。原文儒释道三家是相互提出问题，然后站在各自不同的立场来辩论
  • 有观点认为魏晋南北朝以后中国的思想家大都转向了佛教，所以汉以后少有先秦诸子式的大思想家；这一时期佛教确实涌现大量理论家。原文有一种观点认为，魏晋南北朝以后，中国的思想家大都转向了佛教。
  • 佛教与中国本土思想的碰撞经历很长时间，不少话题延续至今，有的是庙堂唇枪舌剑、广场互不相容，并伴随惊心动魄的历史经历，可见不同思想所能产生的强大力量。原文从中亦可以看出不同思想所能产生的强大力量
  • 了解历史事件背景就能看到历史人物栩栩如生，远非今人所理解的刻板；如罗什僧团与觉贤僧团不相容，昙无谶、慧思、达摩、惠能、玄奘等身上都有故事，当时是触目惊心甚至你死我活。原文比如鸠摩罗什的僧团和觉贤尊者的僧团，彼此之间互不相容
  • 佛教修行界未必一派祥和：修行者理念不同，常各说各话互有微词；佛教内部很多宗派之间实际是『井水河水』的关系，自古至今如此，大家心知肚明。原文佛教内部很多宗派之间，实际上是井水河水的关系
  • 思想具有力量，不同思想模式产生不同力量，最终转变为世间行为。原文思想具有力量，不同的思想模式会产生不同的力量，最终会转变成为世间行为。
  • 罗什时代前后出现很多思想学派，逐渐进化为宗派；各宗派想以不同角度、方法诠释教理教义和行法成就模式。原文鸠摩罗什时代前后，佛教出现了很多思想学派，从这些学派慢慢进化到我们现在看到的佛教宗派。
  • 学派与宗派的区别：学派是学术性的（三论、四论、涅槃、地论按现在标准算学派）；宗派要有完整理论体系和独特行法。原文宗派是建立在完整的理论体系下
  • 魏晋南北朝到隋唐建立的学派宗派包括成实宗、俱舍宗、涅槃宗、三论宗、地论宗、净土宗、禅宗，稍晚有天台宗、华严宗、法相唯识宗、律宗；另有未成宗派的学派，其思想已融入这些宗派。原文还有一些其他学派，虽然没有形成宗派，但是思想都已经融合到了这些宗派的思想中。
  • 三论宗：以中论、十二门论、百论为根本，吉藏（嘉祥师，549至623年）集罗什、僧肇、僧诠、法朗三论学及性宗思想建立；加龙树百卷《大智度论》为四论宗。原文以三论宗为基础，加上龙树菩萨的百卷《大智度论》，即是四论宗。
  • 地论宗：以世亲《十地经论》为根本，亦有龙树《十住毗婆沙论》，皆围绕华严经《十地品》；代表慧远（523至592年）住净影寺，称净影师，以别于东晋净土宗慧远。原文亦是围绕华严经的《十地品》来说
  • 嘉祥师与净影师曾注净土宗经典，对净土思想有贡献，所以净土修行者较熟悉；但两位的成就主要体现在三论宗和地论宗。原文但他们的成就，实际上主要体现在三论宗和地论宗。
  • 涅槃宗以《大般涅槃经》为根本；罗什时代有好几种版本，最常见昙无谶四十卷本与慧严慧观据法显译本整理的三十六卷本，思想体系较完整；罗什译《遗教经》等份量小、体系不如其完整。原文这是份量最大的两种译本，其思想体系比较完整。
  • 净土宗：昙鸾（476至542年）注世亲《往生论》，思想影响深远，若非有道家思想背景甚至可成净土宗祖师；后有道绰、善导（613至681年，与玄奘同期，与昙鸾相差百多年）建立整体理论框架。原文如果不是因为有道家思想背景，昙鸾甚至可以成为净土宗的祖师。
  • 禅宗思想并非始于达摩，而是来自罗什时代译出的般若部经典；般若经典演化成禅宗思想核心，《法华经》演化成法华宗（天台宗）。原文禅宗思想并不是从达摩祖师开始的，而是从鸠摩罗什时代翻译的般若部经典而来的。
  • 禅宗思想核心在般若，天台宗核心在中道，二者在罗什时代就已存在。原文不论是禅宗般若思想还是法华宗中道思想，在鸠摩罗什时代就已经存在。
  • 达摩约西元520年来华（距罗什来华约120年），所传禅宗以《楞伽经》为核心，延续到五祖；传到六祖惠能转到《金刚经》，虽仍契合禅宗思想，但《金刚经》与《楞伽经》的成就模式并不相同；《金刚经》从此对后来中国文化产生深远影响。原文但是《金刚经》和《楞伽经》的成就模式并不相同。
  • 法华宗即天台宗，实际创立者隋代智𫖮（538至597年），但思想核心从罗什时代开始；中道思想在罗什弟子论著中已很深入，经慧文、慧思（515至577年，天台二祖）完善成系统，智𫖮集大成。原文《法华经》中道思想在鸠摩罗什弟子们的论著中就已经体现出来，并且已经相当深入。
  • 华严宗比法华宗晚不到一个世纪，从法顺（杜顺，557至640年）开始，经智俨（二祖，602至668年）、法藏（三祖，643至712年，贤首国师）发展完善，四祖澄观（737至838年，清凉国师）未见法藏。原文澄观法师并没有见到华严宗三祖法藏。
  • 将祖师放在同一时代对照：智俨、玄奘（602至664年）、弘忍（601至674年）、道宣（596至667年）同时；善导、法藏、惠能（638至713年）、李通玄（634至730年）大体同时；把历史事件串起来易记，这些人之间有故事并相互影响思想。原文这些法师都是处在同一时代，皆是西元600年前后时期的人。
  • 玄奘西元627年出发，628年到印度，642或643年回长安，法藏刚出生；智俨时四十几岁；法藏二十几岁受戒出家约660年，玄奘已近入灭。原文法藏大概二十几岁受戒出家，是差不多西元660年前后的事
  • 智俨未见八十华严，著《华严经搜玄记》注六十华严，判为七处八会，法藏《华严经探玄记》沿用；澄观《华严经疏钞》注八十华严，因增一处经首看似增一会，判为七处九会，继承前法。原文后来法藏的《华严经探玄记》依然沿用七处八会的划分方法。
  • 法藏曾参与八十华严的翻译工作。原文法藏法师曾经参与了八十华严的翻译工作。
  • 李通玄（634至730年）为八十华严做注《新华严经论》四十卷，『新华严经』指八十华严；八十华严698年译出，他约720年前后八十几岁才拿到，用十年写成，后与经本合为百二十卷；提出十处十会划分及不少异于前人的说法，对后来华严学很有影响。原文后人把这部论和经本合在一起，成为今天看到的百二十卷《新华严经论》。
  • 华严宗人物时间顺序：杜顺→智俨→法藏→李通玄→澄观，其间穿插天台、禅、净土、法相、律等宗祖师和隋唐重要历史事件。原文从时间顺序上看，是从杜顺和尚，到二祖智俨、三祖法藏，然后是长者李通玄、四祖澄观等等
  • 明了各宗派祖师的生活时代和年代关系，对了解宗派思想如何建立演化非常重要：了解其时代的经典背景和社会背景，就知其依据哪些经典；若某些经典当时未入中国或未见到，其重要思想就体现不出来，甚至理论与之相悖。原文那么这些经典中的重要思想，就可能在他们的论著中体现不出来，甚至他们的理论言说会和这些经典相悖。
  • 判教是佛教整体理论的结构划分，方法很多，隋唐时代尤盛；目前汉地主要以天台宗与华严宗判教为主，另有一教说、两教说、甚至十教说，彼此相互影响又各有缘由。原文还有一教说、两教说，甚至有十教说。
  • 天台宗依『藏通别圆』判为四教，出自智𫖮；华严宗依『小始终顿圆』判为五教，两种判教现在大德讲经时经常提到。原文这两种判教思想在当今大德们讲经时经常提到。
  • 华严五教划分出自杜顺『五教止观』，亦有天台思想影子；一般初祖二祖只提出架构，到二三代才成熟，但杜顺的五教止观直接影响法藏的小始终顿圆；智俨提出十玄门，法藏、澄观完善；五教十玄门在法藏时系统化成为华严宗核心思想体系。原文五教十玄门在法藏法师时期得到了完善和系统化，成为后来华严宗的核心思想体系。
  • 杜顺五教止观的五门：法有我无门、生即无生门、理事圆融门、语观双绝门、华严三昧门；『小始终顿圆』是这五教分类的结论，为最初种子。原文『小始终顿圆』的判教方法就是这五教分类的结论，这是最初的种子所在。
  • 澄观时代各宗派思想基本已建立，他继承智俨、法藏学说，完善了华严宗理论体系。原文法师继承了智俨和法藏的思想学说，完善了华严宗的理论体系。
  • 法相唯识宗与华严宗同时代，以玄奘带回的《瑜伽师地论》《成唯识论》《解深密经》为根本；法藏年轻时在玄奘译经院做过工作，听唯识理论觉得不相应，离开，到智俨处学华严（时智俨六十几岁，华严思想最成熟）。原文法藏在玄奘法师的译经院听闻唯识理论，觉得不相应

例子与比喻

佛教修行界并非一派祥和，思想具有力量

鸠摩罗什僧团与觉贤尊者僧团互不相容；昙无谶、慧思、达摩、惠能、玄奘等人身上也都发生过许多故事。

如今看是生动的历史，当时却是触目惊心甚至你死我活；不同思想模式产生不同力量，最终转变为世间行为。原文比如鸠摩罗什的僧团和觉贤尊者的僧团，彼此之间互不相容，很有故事。

华严宗三祖法藏与玄奘、智俨的渊源

法藏643年出生，正是玄奘取经回到长安前后；他二十来岁时在玄奘的译经院工作，听闻唯识理论觉得不相应，便离开，去当时六十几岁、华严思想最成熟的智俨处学华严。

把人物年代串起来，可以看到同时代祖师之间的相互关联和影响。原文法藏在玄奘法师的译经院听闻唯识理论，觉得不相应，后来离开了玄奘的译经院，到智俨法师那里学习华严。

李通玄与《新华严经论》

八十华严698年译出，李通玄二十年后、八十几岁时才得到这部经，用十年写成四十卷《新华严经论》，提出与华严宗不同的十处十会划分。

李通玄介于法藏与澄观之间，对后来的华严学思想很有影响。原文长者是在八十华严译出之后二十年才见到这部经。

七处八会与七处九会的来历

智俨、法藏依六十华严的八处经首判为七处八会；八十华严多了一处经首，看上去多了一会，澄观便判为七处九会。

华严宗的会数划分来自所依版本的经首数目，是沿用同一方法的结果。原文因为对比八十华严，六十华严少了一处经首，所以在划分上是八会。

怎么用

怎样记住祖师们的年代关系原文按照这个时间顺序，就能知道643年是什么时间，如果把这些历史事件串起来，就比较容易记住。
  1. 以玄奘法师为坐标：627年出发去印度，642或643年回到长安
  2. 对照：法藏643年出生，智俨当时四十几岁
  3. 法藏约660年前后受戒出家时，玄奘已快入灭
  4. 把这些历史事件串起来记
怎样借年代背景读懂祖师论著原文因为了解了那位祖师所生活的时代，了解其所处时代的经典背景和社会背景，再去看他们的论著，就能知道他所依据的经典情况
  1. 了解这位祖师生活的时代
  2. 了解当时的经典背景和社会背景
  3. 判断他所依据的经典有哪些、哪些经典当时未入中国或他未见到
  4. 据此理解其论著中为何缺少某些思想，甚至与这些经典相悖

  • 六十华严七处八会：在这个注解中，智俨把六十华严分作七处八会。
  • 八十华严七处九会：于是八十华严被划分作七处九会，依然继承智俨和法藏的划分方法。
  • 李通玄十处十会：李通玄提出华严经十处十会的划分模式
  • 六十华严八处经首 / 八十华严增一处经首：这个划分结果是从六十华严的八处经首得来的。
  • 新华严经论（八十华严注）：『新华严经』即是指八十华严，是针对六十华严来说。
  • 楞伽经与金刚经（禅宗所依）：达摩祖师所传的禅宗思想本来以《楞伽经》为核心
  • 大般涅槃经（四十卷、三十六卷）：北凉昙无谶尊者翻译的四十卷本
